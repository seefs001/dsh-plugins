## 环境准备

在仓库根目录安装依赖：

```bash
pnpm install
```

## 目录结构

```text
packages/<name>/
├── package.json        # name = dsh-<name>, dsh.bundle, 可选 dsh.client
├── cordis.patch.yml    # bundle patch，至少插入 dsh-<name> 行
├── lib/index.js        # Host 入口（ESM）
├── lib/client.js       # 可选浏览器入口（window.__ModuleLoader__.load）
├── locale/{en,zh}.json # Plugins 页面展示的 meta.title 与 meta.description
├── icon.svg
├── test/*.test.js      # node:test 单元测试
└── README.md
```

绝大多数插件是无需构建的原生 ES 模块。三个例外：

- `diagram-preview`：升级图表库后运行 `pnpm --filter dsh-diagram-preview build` 重新生成懒加载渲染器分片。
- `pi-tools`：浏览器入口在根目录 `client.js`；改动 Go runner 或 Pi 依赖后运行 `pnpm --filter dsh-pi-tools build:runner:all`。
- `message-actions`：浏览器源码在 `src/client.js`，运行 `pnpm --filter dsh-message-actions build` 生成 `lib/client.js`。

## 静态检查与测试

```bash
pnpm run check     # oxlint + validate.mjs + node:test
pnpm run pack:dry  # 演练所有包的 npm pack
```

检查链路强制执行以下规则：

- **Oxlint（`.oxlintrc.json` + `scripts/oxlint-plugin.mjs`）**：
  - `correctness` 与 `suspicious` 均为 error，`--deny-warnings`；
  - `dsh/no-comments`：禁止注释，仅放行 shebang、文件头开源协议声明、单行 URL 与单行 `// external: <原因>`（记录不可改动的外部依赖或宿主限制）；
  - `dsh/no-suppression-comments`：禁止 `oxlint-disable`、`eslint-disable`、`@ts-ignore`、`@ts-expect-error`、`@ts-nocheck`；
  - `dsh/no-legacy-compat`：禁止残留旧版兼容标识。
- **清单与文档校验（`scripts/validate.mjs`）**：
  - 校验包名、版本、目录、`engines.dsh`、`files`、`exports`、`cordis.patch.yml`、`dsh.client` 与 `locale/{en,zh}.json`；
  - 校验 `apps/docs/lib/plugins.ts`、`apps/docs/content/docs/plugins/*.mdx`、`meta.json` 与根目录 `README.md` / `README.zh.md` 同步。

## 文档站

```bash
pnpm run docs:dev        # 本地预览（http://localhost:3000）
pnpm run docs:typecheck  # fumadocs-mdx + next typegen + tsc
pnpm run docs:build      # 静态导出到 apps/docs/out
```

新增插件时，在 `apps/docs/lib/plugins.ts` 添加目录项、在 `apps/docs/content/docs/plugins/` 新增 `.mdx` 文件并加入 `plugins/meta.json`。
