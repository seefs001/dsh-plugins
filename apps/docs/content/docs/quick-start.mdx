---

下文命令以 `web` profile 为例，使用时将 `--profile` 替换为实际运行的 profile；带 Web 部分的插件需在 `dsh web` 中使用。

## 从 GitHub 安装

<Steps>
<Step>

### 选择插件目录名

在 [插件目录](/docs/plugins) 找到目标插件，记下目录名（例如 `model-reference`）。

</Step>
<Step>

### 运行安装命令

<InstallCommand slug="model-reference" />

也可以在 Web 界面的 **Plugins** 页面直接粘贴同一条 `github:` 地址。

</Step>
<Step>

### 让插件生效

- 返回 `applied`：Host 侧立即生效；
- 返回 `restart-required`：重启该 profile 的 DSH；
- 包含 Web 部分的插件：刷新浏览器页面即可加载。

</Step>
</Steps>

## 从本地仓库安装

```bash
git clone https://github.com/seefs001/dsh-plugins.git
cd dsh-plugins
dsh plugin --profile web add "link:$PWD/packages/model-reference"
```

## 批量安装命令

按分类整理的完整安装命令，按需复制对应行即可：

<InstallAll />

部分插件需要特定 DSH bundle 或本机工具，安装前可查看 [依赖与运行](/docs/compatibility)。

## 移除插件

在 **Plugins** 页面停用或移除对应 bundle，或运行：

```bash
dsh plugin --profile web remove dsh-model-reference
```

移除插件会保留已写入 Host storage domain 与 DSH 原生配置中的数据。
