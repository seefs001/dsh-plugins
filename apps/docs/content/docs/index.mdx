## Host 与 Web

- **Host**：运行在 DSH 后端进程，负责配置写入、storage domain 持久化、凭据读取、工具注册与外部命令/API 调用。
- **Web**：运行在 `dsh web` 浏览器界面，负责输入框扩展、侧边栏面板、消息渲染与设置弹窗。

每个插件页顶部的信息框都标明了运行位置与前置依赖。
