dsh-plugins 是 seefs 维护的 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（DSH）插件集。每个插件是一个独立 bundle，安装到某个 profile 后可以单独启用、停用和移除，不需要装整套。

## Host 和 Web

DSH 插件分两部分。Host 部分运行在 DSH 服务进程里，处理配置、存储、工具和模型请求。Web 部分运行在 `dsh web` 打开的浏览器页面里，负责输入框、侧边栏和消息显示。

只有 Web 功能的插件也带一个空的 Host 入口，因为 Loader 加载 bundle 时需要它。这些插件不会给终端界面添加相同的交互。每个插件页顶部的信息框写明了它的运行位置。

<Callout>
这是社区项目，不是 DeepSeek 官方插件。整套插件支持 DSH `>=0.2.2-rc.1 <0.3.0`，其中几个插件要求 rc.2 或更新的构建，见 [版本与边界](/docs/compatibility)。
</Callout>
