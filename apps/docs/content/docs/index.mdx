## 运行架构：Host 与 Web

DSH 插件分为两部分：

- **Host 部分**：运行在 DSH 后端进程，负责配置保存、storage domain 持久化、凭据读取、工具注册与外部进程/API 调用。
- **Web 部分**：运行在 `dsh web` 浏览器界面，负责输入框扩展、侧边栏面板、消息渲染与弹窗设置。

仅包含浏览器功能的插件仍会带有一个空 Host 入口（供 Loader 加载 bundle），不会向终端模式注入界面交互。每个插件页顶部的信息框均写明了运行位置和额外要求。
