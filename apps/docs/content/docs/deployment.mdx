title: GitHub Pages
description: 通过 GitHub Actions 静态导出并部署文档站到 GitHub Pages。
---

文档站使用 Next.js `output: 'export'` 生成静态产物到 `apps/docs/out`，在线地址：

```text
https://seefs001.github.io/dsh-plugins/
```

## 启用

1. 将文档改动合入 `main`。
2. 在仓库 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。
3. 在 **Actions → Documentation** 手动运行一次，之后相关改动会自动触发部署。

## 子路径构建

GitHub Pages 项目站点挂载在 `/dsh-plugins/`，构建时通过环境变量指定前缀：

```bash
NEXT_PUBLIC_BASE_PATH=/dsh-plugins pnpm run docs:build
```

本地预览 `pnpm run docs:dev` 挂载在根路径 `http://localhost:3000`。若切换到自定义根域名，移除工作流中的 `NEXT_PUBLIC_BASE_PATH` 重新构建即可。
