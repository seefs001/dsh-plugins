## 外部运行注意

- **ACP 会话集成**：外部 CLI（Cursor、Antigravity、Claude Code 等）使用自身账号与权限运行，不受 DSH 工具沙箱约束。
- **Pi 工具**：搜索与文件查找调用运行环境中的 `rg` 与 `fd`（可通过 `rgCommand` / `fdCommand` 覆写）。
- **AI 吉祥物**：首次渲染会向 `selinlee.github.io` 请求静态角色图片，素材适用独立的非商业条款。
