## 需要先启用的 DSH bundle

| 插件 | 需要 | 缺少时 |
| --- | --- | --- |
| 自动审查模型 | `@deepseek-ai/dsh-experimental-auto-review` | 插件可以安装，但没有 Auto review 请求可改道，输入框也不显示审查标签 |
| Git 变更 | Change requests & worktrees（`@deepseek-ai/dsh-experimental-forge-bundle`） | 输入框下方不出现入口 |
| 分支切换 | Change requests & worktrees | 新会话页没有可替换的分支入口 |
| 会话分组、自动审查模型、Wait, what?、Switchboard | `@deepseek-ai/dsh-storage-domain` | 默认 profile 已包含 |

插件不会替你启用这些 bundle。

## 插件不会做的事

这些插件都不修改 DSH 源码，也不改写其他插件的存储文件。

| 插件 | 边界 |
| --- | --- |
| # 引用模型 | 插入的是提示词里的模型引用，不切换当前会话的模型 |
| 快速模式 | 只对 `openai-responses` 路由生效 |
| 子代理模型 | 只显示，不改路由、推理强度或提示词 |
| 自动审查模型 | 只改 `purpose: "auto-review"` 的请求，主对话不受影响 |
| 工作区管理 | 只移除 DSH 的工作区记录，不删除目录、文件或会话 |
| 分支切换 | 只切换已有的本地分支，不 fetch、不建分支、不 stash、不强制切换；共用这个目录的会话和终端都会看到新分支 |
| 上下文压缩状态 | 只显示状态，不触发压缩，也不会让压缩变快 |
| 引用跳转 | 只能找到页面已经加载的消息 |
| Wait, what? 回复解释 | 解释不进入对话，不调用工具 |
| 联网搜索 | 可用时对相关 Agent 隐藏内置 `web_search`，不改 `web_fetch` |
| Pi 工具 | 只在 `pi` 预设里生效，不改默认预设或其他会话；复用 DSH 的权限、沙箱和 MCP 连接，不另起 MCP 客户端，也不复制凭据 |
| 保持唤醒 | 只阻止 macOS 闲置休眠，不阻止合盖、手动休眠或关机，不改永久电源设置 |

## 安全与外部请求

- 联网搜索、Wait, what? 和自动审查模型会把相关文本发给你选择的模型服务。
- AI 吉祥物首次显示时会从 `selinlee.github.io` 加载角色图，请求不带对话内容。角色素材不属于 MIT 许可，有单独的非商业条款。
- Switchboard 会把会话流式转发到你配置的中继。不受信任的运行只能使用只读工具，详见 [Switchboard](/docs/plugins/switchboard)。
- 插件管理会改变整个 profile，影响这个 profile 下的所有会话。

## 验证范围

仓库的 `pnpm run check` 运行 oxlint、manifest 校验和已有的 `node:test` 测试。它们检查源码和包元数据，不代表界面已在真实的 DSH 页面里渲染正确。界面相关的改动仍需在安装了插件的 DSH 里实际查看。
