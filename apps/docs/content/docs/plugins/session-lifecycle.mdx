## 侧栏分区

- **需要你**：汇总待处理的审批、计划审阅和提问，且只有这类会话计入角标。子任务归并到主会话名下，点击直接打开实际提问的会话；普通 fork 独立显示。
- **进行中**：正在运行、排队执行或存在运行中子任务的会话默认折叠。置顶会话与当前打开的会话保留原位；搜索时展示原生结果。
- **最近返回**：近 24 小时内结束、唤醒或取消归置的会话，按返回时间排列。
- **已暂缓 / 已归置**：通过会话右键菜单按预设或自定义本地时间暂缓，或归置到底部收纳架；所有位置调整均支持撤销。暂缓期间已有普通提问可等到提醒时间，出现新请求或新失败会提前唤醒。向已归置的会话发送新消息会自动放回列表。

在 **待处理** 面板的 **设置** 中可开关「折叠进行中的会话」，或修改自动归置期限（默认 7 天，可关闭）。Host 每分钟检查一次，置顶、进行中、排队、已暂缓、待处理、已归档或设为永不自动归置的会话不参与自动归置。

## 待处理面板与 Agent 工具

**待处理** 面板集中列出所有分区、单个问题的「稍后回答」、未读轮次结果（`session-lifecycle-outcome` 投影）、未被主会话覆盖的子任务失败以及已登记交付物。支持单条或批量标为已读，从面板跳转至会话后可在顶部点击返回原位。页面有焦点且加载对应轮次结束事件时自动标为已读；未生成结果投影的旧会话可按小批次手动补读。

共享状态（`session_lifecycle`）、摘要接口（`session_lifecycle_summary`）仅供 profile owner 访问。如需让 Agent 整理当前顶层会话，可在工具选择器中启用 `session_lifecycle`。

## 可选提取式摘要

在 **待处理** 面板的 **设置** 中进入 **摘要**，profile owner 可指定**一个模型**和**一个精确工作目录**开启自动摘要：

1. 仅对启用后新完成、位于主会话且不含代码块、常见密钥特征或交付物的长回复，在 10 秒稳定窗口后触发。
2. 发送回复开头至多 8 句（上限 2,400 字符），让模型返回 **1 到 2 句原文序号**，界面展示原文并附来源对照。
3. 每日额度上限 **12** 次（含试算，按 UTC 日期重置），最多缓存最新 **100** 条结果。

<Callout type="warn" title="请勿为敏感目录开启摘要">
规则无法识别自由文本中的所有敏感信息。请仅对日常研发或审阅目录开启，并确认信任所选模型服务。
</Callout>
