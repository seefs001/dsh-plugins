## 看侧栏，不用轮流打开每个会话

- **需要你**：只计算待处理的审批、计划审阅和提问。子任务归到主会话名下，点击会打开实际发起请求的会话。普通 fork 独立显示。
- **进行中**：运行、等待下一轮或还有子任务在工作的会话默认折叠。置顶行和当前打开的工作会话保留原位。搜索时显示原生结果。
- **最近返回**：近一天结束、唤醒或取消归置的会话按返回时间排列，不按后台消息重新排序。
- **已暂缓 / 已归置**：在会话菜单里选预设时间或自定义本地时间暂缓。已有的普通提问可以等到提醒时间；新请求或新失败会提前唤醒，正常完成不会。归置不停止或归档会话，发新消息会让它回来。

在 **待处理 → 设置** 可关闭「折叠进行中的会话」，或调整自动归置期限（默认 7 天，也可关闭）。Host 每分钟检查；置顶、运行、排队、已暂缓、有待答问题、已归档或设为永不自动归置的会话不参与。侧栏移动不改原生排序或分组关系。

## 回看结果与稍后回答

**待处理** 面板保留单个问题的「稍后回答」，同会话的其他请求不会一起消失。可回看主会话的轮次结果、未被主会话结论覆盖的子任务失败，以及已登记的交付物。支持单条、批量标为已读，在会话顶部可以返回刚才查看的位置。只有当前页面有焦点且已加载相应轮次结束记录，才会自动标为已读。旧会话按小批次补读，不会因此启动 agent 或生成 AI 摘要。

## 从旧收件箱切换

**先停用旧的 dsh-inbox，再启用本插件**。不要清理 profile 数据。两者沿用相同的结果投影和摘要存储，所以现有摘要开关、模型、目录、额度和缓存会继续生效。每个曾用过收件箱的浏览器首次打开新插件时，会把有效的已读序号和未过期的「稍后」提醒导入 Host，写入成功后才清理相应的本地标记。

共享状态和摘要接口仅供 profile owner 使用。Pi 模式不需要改 DSH 核心；如要让 agent 整理自己的当前会话，可从 Pi 工具选择器启用 `session_lifecycle`。

## 可选提取式摘要

在 **待处理 → 设置 → 摘要** 中，profile owner 可以选择**一个指定模型**与**一个精确工作目录**开启提取式摘要（其他目录保持关闭）：

1. 只针对开启之后、在主会话完整结束且无代码块/敏感特征/交付物的长回复，在 10 秒稳定窗口后触发。
2. 只向模型发送最终报告开头至多 8 句（上限 2,400 字符），要求模型返回 **1 到 2 句的原文序号**（不改写原句，界面标为 AI 选取并保留原文对照）。
3. 每日预算上限 **12** 次请求（包含点击 **试运行一次**，按 UTC 日期重置），结果最多缓存最新 **100** 条。

<Callout type="warn" title="请勿为包含敏感信息的目录开启摘要">
虽然插件会跳过包含常见密钥特征或代码块的文本，但自由文本匹配无法做到绝对识别。请只为日常研发或审阅目录开启，并确认你信任所选模型服务。
</Callout>
