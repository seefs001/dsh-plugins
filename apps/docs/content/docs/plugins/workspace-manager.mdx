## 使用步骤

<Steps>
<Step>

### 打开工作区管理

在左侧栏点击 **工作区管理**，查看已登记的工作区名称、路径与关联会话数，支持按名称或路径搜索。

</Step>
<Step>

### 检查目录状态

点击 **检查目录**，Host 核对每个工作区路径并标注状态：

- **目录存在**
- **目录不存在**
- **不是目录**
- **无法检查**（权限不足或 I/O 错误）

</Step>
<Step>

### 一步式闲置清理（Clean up）

点击侧栏底部的 **清理闲置** 图标（或工作区管理页顶部按钮），Host 实时扫描并自动跳过当前正在查看的会话与工作区，按类默认折叠列出：

- **失效工作区**（目录不存在或不是目录）
- **遗留后台任务**（所属会话已结束但仍在运行的后台 Job）
- **干净的旧 Worktree**（无任何未提交改动的 linked worktree，移除前再次复查）

每条右侧固定显示文字按钮（**移除** / **停止**），点击即原地执行，也可底部一键全部清理；无可清理项时仅弹轻提示。

</Step>
<Step>

### 单条移除或批量清理

在工作区管理页点击 **清理失效记录** 检查全部工作区（不受搜索过滤影响），确认后批量移除「目录不存在」与「不是目录」的条目；「无法检查」的条目保留。也可在单行右侧点击 **移除**。

</Step>
</Steps>

<Callout type="warn" title="确认外接磁盘或网络卷已挂载">
未挂载的外接磁盘或网络目录在检查时会显示为「目录不存在」，批量清理前请在确认弹窗中核对路径。
</Callout>
