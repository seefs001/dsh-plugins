---
title: 工作区管理
description: 移除已保存的工作区，检查并清理失效目录记录，保留文件与会话。
---

`dsh-workspace-manager` 增加独立的工作区管理页面。**Host + Web**，需要 DSH `>=0.2.2-rc.2 <0.3.0` 和默认 Web profile 的 Workspace 服务。

## 安装

在本地仓库根目录运行，无需构建：

```bash
dsh plugin --profile web add "link:$PWD/packages/workspace-manager"
```

发布到仓库后也可使用 `github:seefs001/dsh-plugins#main&path:/packages/workspace-manager` 安装。

## 使用

1. 刷新网页，在侧边栏打开 **工作区管理 / Workspace manager**。
2. 页面列出全部工作区，包括没有会话或目录已被删除的记录。输入名称或完整路径可搜索。
3. 点某条记录的 **移除**，确认后从原生工作区列表和选择器移除。
4. 页面打开时自动检查目录；点 **检查目录** 可重新检查。
5. 点 **清理失效记录**，重新检查全部工作区，核对确认框里的完整路径后批量移除。搜索条件不会限制批量清理范围。

## 清理范围

目录检查在运行 DSH Host 的电脑执行，而不是打开网页的设备。只有不存在、路径本身或父路径不是目录的记录进入批量清理；权限不足和 I/O 错误显示为 **无法检查**，不会进入批量清理。

断开的磁盘和网络挂载也可能显示为不存在，所以插件不会在后台自动移除记录。检查是即时快照，确认前请核对路径。

## 数据保留

删除磁盘目录不会自动删除 DSH 保存的工作区记录。本插件使用原生 Workspace API 移除记录，不直接编辑 storage，不删除磁盘文件、会话日志或正在运行的会话。移除同步沿用原生权限和推送机制。

如果批量移除中途失败，页面报告成功数量和错误，停止后续移除；已经成功的操作不会回滚。插件不保存额外状态，也不需要配置。
