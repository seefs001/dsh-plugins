description: 清理 DSH 保存的工作区列表和失效目录条目，不删除磁盘文件和会话。
---

<PluginFacts slug="workspace-manager" />

把删除或移动过目录后留在侧栏里的旧工作区记录清理干净。只操作 DSH 的工作区注册表，不动磁盘文件，也不删任何会话记录。

## 安装

<InstallCommand slug="workspace-manager" />

## 使用步骤

<Steps>
<Step>

### 打开工作区管理

在左侧栏点击 **工作区管理**，查看所有已登记的工作区名称、路径与关联会话数。支持通过顶部搜索框按名称或路径过滤。

</Step>
<Step>

### 检查目录状态

点击 **检查目录**。Host 会通过只读接口核对每个工作区路径，标注为：

- **目录存在**
- **目录不存在**
- **不是目录**
- **无法检查**（如权限不足或 I/O 错误）

</Step>
<Step>

### 清理或单条移除

点击 **清理失效记录** 会检查全部工作区（不受搜索条件影响），列出所有「目录不存在」或「不是目录」的条目并在确认后批量移除；「无法检查」的条目会自动保留。也可在单行右侧直接点击 **移除**。

</Step>
</Steps>

<Callout type="warn" title="先确认外接磁盘或网络卷是否已挂载">
尚未挂载的外接磁盘或网络目录在检查时也会显示为「目录不存在」。批量清理前请在确认弹窗里核对一遍路径。
</Callout>
