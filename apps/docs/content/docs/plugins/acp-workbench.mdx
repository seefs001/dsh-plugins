<PluginFacts slug="acp-workbench" />

保留 DSH 的输入框、附件、消息时间线、停止按钮和子代理树。外部执行轨迹与人工交互进入当前会话，不再另开一套聊天工作台。默认提供 Cursor、Antigravity 和 Claude Code，也可配置其他本机 ACP CLI；不依赖 Paseo Hub 或 daemon。

## 安装

<InstallCommand slug="acp-workbench" />

先在终端安装并登录 CLI，再到侧栏 **ACP 工作台** 的 **提供方** 页核对命令与参数。Cursor 和 Antigravity 默认使用 `["acp"]`；Claude Code 使用 `claude-agent-acp`，不传参数。填写工作目录后，**检查能力** 只进行 initialize，不发送任务，结果以能力标签展示。

外部 CLI 使用自己的账号、计费、工具和文件权限，**不受 DSH 工具沙箱约束**。插件只处理 CLI 实际发出的审批。完全访问预设只可自动选择 `allow_once`，不能替人授予持久权限；轨迹标明自动或人工回应。不要在命令参数里填写密钥。

## 从项目启动

打开 **ACP 工作台 → 项目**，选择或添加一个目录，点 **新建 Agent**。每次创建独立 DSH 会话，可为同一项目分别打开 Cursor、Antigravity 和 Claude Code。模型和隔离方式可保存成具名启动配置。选择 **独立工作树** 需要启用 DSH 的 worktree 能力；可指定新分支和本地起始 ref。创建会话本身不发送任务。项目列表支持切换、归档和恢复原会话。

找已有会话时，在 **项目会话** 输入名字；也可以组合项目名和会话名，例如 `docs 登录`。切到 **全部项目** 能同时查多个目录，点结果就打开原会话。会话行的 **…** 使用 DSH 原有菜单，可改名、置顶；已归档会话先恢复再打开。项目名可从目录旁的 **重命名项目** 修改，不会改路径。搜索只用目录和会话列表，不查聊天正文或远端 CLI 历史。

找某个 agent 生成的文件，点它所在行的 **查找文件**。例如输入 `reports/summary`，只会列出该会话实际目录中路径匹配的文件，不会搜索聊天或文件正文。不知道产物名时，切到 **浏览目录**，可以逐层查找，也可点上方的目录名返回。此模式不显示隐藏项，但会列出被 Git 忽略的普通文件与文件夹。展开目录只读取这一层的条目；点文件才预览，可从当前行继续在 DSH 的文件侧栏查看。会话中途切换工作树，旧结果不会在新目录打开同名文件。

要接着看已有 shell，在对应会话行点 **会话终端**。这里会实时列出 DSH 仍保留的终端，可区分用户或 Agent 启动、当前由谁控制，以及进程是否已退出。点 **打开终端** 会定位到所属会话的原生终端标签。即使两位 Agent 在同一工作树里运行同名终端，列表也不会混合。单纯展开列表不会接管终端；已经不在列表里的历史命令不能从这里复活。

**项目脚本** 位于每个项目会话行。它从该会话实际目录的 `paseo.json` 读取 `scripts`，不会因为打开面板就运行命令。确认命令全文后，可以在原生 DSH 终端看实时输出，或回到面板查看退出码、输出摘要和停止长驻进程。**运行中** 只表示终端进程还在。

如果服务命令使用 `$PASEO_PORT`，点 **带回环端口启动**，会给命令设置空闲端口和 `HOST=127.0.0.1`。再点 **监测端口**，卡片会显示最近一次 TCP 检查的结果。进程可以仍在运行，但端口连续两次拒绝连接；这时应打开原终端看启动日志。**结束监测** 只停止检查，不会终止服务。普通 **运行** 不会分配端口。固定端口或自定义端口策略不在此入口探测；不会生成公网地址。

### 让两个 Agent 在同一份代码上工作

在项目中展开一个托管工作树会话的 **工作目录**，点 **在这里新建 Agent**，选择 ACP 引擎并创建。比如让一个 Agent 改代码、另一个检查未提交的 diff。第二个 Agent 会直接看到第一个 Agent 保存的文件，但不会收到它的聊天记录或审批，也不会自动开始执行。需要不同模型时，在新会话的原生模型选择器中设置。

打开 **切换同工作树 Agent** 可以直接从聊天切换到其他参与会话。项目页同一位置也会列出参与者，并区分创建者、所选会话和待回应状态。Stop 和审批只作用于对应会话。共享的是文件，不是合并队列；两个 Agent 改同一行时没有自动冲突处理。

### 归档会话与恢复工作树

在会话行点 **工作目录**，可看到会话指向的路径、DSH 记录的托管工作树及其来源、分支和起点提交。这里区分“会话已归档”和“目录已回收”。归档后，DSH 会检查是否仍有会话使用 checkout，以及 Git 能否看到未提交或未跟踪的文件。**忽略规则、skip-worktree 或 assume-unchanged 隐藏的文件不能依赖这个检查保护**，请在确认归档前备份，或在 DSH 工作树设置中选择归档时保留。

归档页可查看回收中、已保留、已回收或失败。若 Host 已重启，没有上次回执并不代表目录已被删除。**恢复会话** 只恢复会话身份；如原目录缺失，再点 **重建缺失的工作树**。DSH 会优先检出原分支；如果分支已不存在，只能从记录的起点提交重建。已有路径不会被覆盖，也不会悄悄转到项目根目录发送 ACP 提示。

### 在聊天中查看工具调用

例如 Agent 连续读了两次同一文件、搜索一次，再修改代码。**概览** 先显示「读取 2 次 · 搜索 1 次」，编辑仍是单独一行，可直接展开 diff。展开查阅记录能看到原来的每次调用、行号和输出，也能从支持文件预览的聊天界面跳到对应行。选择 **逐条** 会列出所有调用，当前浏览器记住这个选择。

联网调用要区分「要求查什么」和「实际传回什么」。**网页搜索** 按 CLI 报告的顺序列出说明和来源，多条来源可按需展开。**抓取网页** 显示目标地址、提取要求和返回文本；**页内查找** 显示页面和查找词。只有状态、没有结果文本时，卡片会说明这一点，不会补写命中、HTTP 状态或网页内容。展开不访问外部网站。

一次调用涉及多个文件时，用 **补丁文件** 切换文件，或选 **全部报告片段** 看原顺序。CLI 只在启动时发过补丁，调用结束后仍标为 **启动时的预览**；如果完成或失败回报里另带补丁，则标出它的来源。只有明确报告移动时才显示旧路径和新路径。切换文件只看历史片段，点报告的位置才打开当前文件。

运行中、失败、带图片、命令、审批和未知调用都不会藏在这类摘要里。能用 ID 匹配时，工具行会显示「等你审批」「已拒绝」或「预设自动允许」等回执。**查看回执不会替你回答**；没有收到决定时也不会把工具完成当成已批准。原始事件仍可按序查看。

决定前先看输入框下方的审批卡。卡上是 CLI 随这次请求提供的路径、参数或补丁；各按钮下方写明是允许还是拒绝，以及是否可能影响后续请求。CLI 有时只发调用 ID，不带预览。如果有 **查看最初的工具调用**，可以核对启动时的报告，但不要把早先的参数当成本次请求的授权范围。事后点轨迹里的 **查看审批请求**，可以核对原请求、当时给出的选项及对应决定。这个视图不能授权。

### 查看 CLI 自己启动的子任务

如果 Claude Code 同时派出两个任务，在聊天轨迹中展开 **本轮 CLI 子任务**，就能看到哪个启动调用还在执行、哪个有审批等待处理。点任务名称或工具行上的 **查看子任务**，只看它直接发起的读取、命令、计划、进度和审批回执。遇到嵌套任务可再进入一层；**完整轨迹** 返回按时间排列的记录。带图或音频的任务进展可点预览，无须翻 JSON。

这个视图只读。子任务的中间输出不会拼进父 Agent 的最终答复；审批仍在原会话回答。「启动调用：已完成」是 CLI 报告的调用状态，不保证后台进程已经结束。若没有父调用标识，插件不会靠标题猜测。要独立发消息、停止或接续，请使用 DSH 原生子代理。

### 审阅多位 Agent 的结果

**项目 → 项目审阅** 先列出等待回应的审批和问题，再按结束时间列出每一轮 ACP 结果。看摘要后，点 **本轮轨迹** 查工具调用、输出和差异，或打开对应根会话/子代理看完整回复。点 **标为已审阅** 只确认这一轮；在其他窗口查看、打开项目或审阅别的轮次都不会代你放行审批。升级前的运行可在 **全部结果** 找到，不会突然堆成未读。

要从一次调用回到代码，点结果卡上的文件名，或在 **本轮轨迹** 中展开读取、搜索或编辑调用。**定位搜索结果** 可以直接选命中的文件和行，也可在 CLI 子任务里使用。预览按这次调用记录的目录读当前文件；即使会话后来换了工作树，也不会在新目录找同名文件。文件不存在会报错，记录的行已超出文件时可从头读。关闭预览会回到刚用过的文件链接。

点 **工作树改动** 读取所选会话此刻的 Git 状态。可以看工作树相对 HEAD、已暂存、未暂存，或指定分支基线对比；展开文件查看补丁。它反映当前工作目录，同一目录的多位 Agent 可能共同产生这些改动，并非历史快照。未启用 DSH Forge 时仍可看已记录的 ACP 调用轨迹。

要看已经提交的改动，在 **对比范围** 选 **分支上的提交**，选择基线和提交。默认只看该次提交；若其后有连续的第一父提交，可用 **比较到** 选结束点。查看 merge 时，旧侧是它的第一父提交。点补丁右侧行号读到的是结束提交里的文件，不会带入暂存区、磁盘上的修改或未跟踪文件。如果基线已经移过所选提交，刷新会提示重新选择。

查看工作树改动时，点补丁**右侧行号**，会从该行预览文件；点 **查看文件** 则从头读。例如主项目和独立工作树都改了 `src/app.ts`，这里打开的是所选会话的工作树版本。还可点 **在文件侧栏打开**，带着行号回到对应会话。**已暂存** 只显示 Git 索引，不跳到可能已有其他改动的磁盘文件。文件已变动而无法定位时，请刷新比较。

要看删掉了什么，点**左侧行号**。预览先显示补丁里已有的旧行，保留原行号并标出中间缺失的段。**读取完整旧版本** 会按比较范围读取 Git：未暂存读索引；与 HEAD 比较或已暂存读 HEAD；一组提交读起始提交的第一父提交。重命名后仍用旧路径。Forge 没有给出确定的旧提交时，只提供补丁片段；不会打开磁盘上的同名文件。

### 定时启动或唤回 Agent

打开 **项目 → 定时任务**。选择已有根会话可沿用它的 ACP 引擎、模型和独立 worktree；也可让 DSH 在项目目录首次到期建一个会话并复用，或每次新建。新建模式使用 Host 默认或所选 DSH Agent 预设。设置延时、间隔、每天的当地时间或五字段 cron 后，核对指令再确认。每天和 cron 的时区均可修改。

列表只显示投递到当前项目的任务。**投递历史** 可打开实际接收消息的会话，查看执行轨迹和审批。**已投递不等于已完成**。立即投递同样会触发真实 Agent，遵循 DSH 的最小投递间隔。暂停不撤回已经入队的消息。正在定时唤回的会话默认不能归档；在 DSH 显式选择停止并归档会移除该会话的活动任务，恢复会话不会自动恢复已删除的任务。

## 直接执行当前会话

1. 在原模型选择器中选择 ACP 提供方下的具体模型。
2. 如果尚未载入模型目录，到 **ACP 工作台 → 提供方** 填写工作目录，点击 **刷新模型**，勾选需要显示的候选模型，再点击 **保存模型选择**。刷新只新建空 ACP 会话读取目录，不发送任务，也不自动加入主选择器。后续连接及配置更新不改变已选列表。
3. 使用原输入框提问、发送附件，在原时间线阅读回复。每轮的 **执行轨迹** 按发生顺序直接向下列出工具、计划、审批结果和 CLI 日志，结束后不再自动收起。工具行直接显示动作、文件或命令和执行状态。展开可以看带行号的读取结果、文件 diff、终端输出、按文件分组的搜索结果或网页来源。在聊天里点展开后的文件路径可打开 DSH 文件预览。原始参数收在「技术详情」，无需读 JSON 才能判断执行了什么。
4. 权限请求、问题和计划审批以卡片出现在输入框下方。使用原停止按钮取消，已输出内容保留。
5. 模型和引擎切换使用原选择器。首次发送、断线和上一轮失败时，输入框下方给出对应提示；重新连接不会重发任务。点原模型菜单的 **CLI 设置**，可以留在当前对话调整 CLI 模式、运行命令和查看用量；普通 DSH 模型不增加菜单项。完整记录在 **ACP 工作台 → 活动**。

**看 MCP 调用：** 在执行轨迹里找到 **MCP 工具**，行上会显示「服务 / 工具」。例如文档查询返回了一组记录，可展开结果列表对照各行，再切回 **调用参数** 看查询条件。图片、文本和资源按返回顺序显示。审批卡里看的则是本次请求；如果 CLI 只附了供人阅读的参数说明，卡片会注明没有原始参数。查看记录不会再次调用服务。

**看命令输出：** 在执行轨迹里展开命令。支持流式回报的 CLI 会在运行中更新终端卡；若工具又给了不同的汇总结果，可以在 **终端回报** 与 **工具另报的输出** 间切换。没有退出码时不推定为 `0`。长输出只显示末尾 32 Ki 字符并提示截断；原始事件保留在活动记录。卡片只读，不能输入、重跑或给命令授权。

**查看上下文还占多少：** 输入框下方点 **CLI 上下文 · 最近报告**，查看当前外部会话上次报告的占用和窗口大小。展开也能看到报告时间，以及 CLI 提供的模型和累计费用。旧轮次的执行轨迹保留当时的报告；**CLI 会话累计 token** 表示截至该轮结束的总计，不是单轮费用或账号剩余额度。

**回答 Agent 的提问：** Claude 的问题直接出现在 DSH 请求卡片。选一个或多个选项，也可在对应题目的补充框输入自己的回答；展开选项示例不会提交。点 **提交回答** 发给本次提问的 CLI，点 **不回答** 可拒答。提问和工具审批各自处理。CLI 撤回问题后不能再回答。

**对照清单和方案：** 在执行轨迹查看每步状态、高优先级标记和完成数；点方案标题可读 CLI 当时报告的 Markdown 原文。若附带文件，点 **查看当前文件** 才读取磁盘。新版 ACP 按计划 ID 更新，一份方案被移除时，其他清单仍保留。计划卡片只读，需要审批时仍在 DSH 的请求卡片上回答。

**从 CLI 旧会话继续：** 在首次发送前点输入框下方的 **接续 CLI 会话**，选择当前项目的记录。**在这里接续** 只连接，不发送任务；已由 DSH 接管的记录会打开原会话。CLI 返回的前文可按需展开查看，不作为新消息重放。

**保留原对话，另试一种做法：** 在相同工作目录的另一个 DSH 会话选择同一 CLI，先不要发送消息。在 **接续 CLI 会话** 中找到原记录，点 **从副本继续**。支持复制并恢复历史的 CLI 才有这个按钮。副本复制 CLI 已保存的最新上下文，设置中会注明来源；之后发给副本的消息不会写回原对话。文件仍在同一个工作目录，不会产生新工作树。

主选择器只显示已勾选保存的模型。选择具体模型后，插件先请求 CLI 切换模型，再发送本轮任务；切换失败不会发送任务。`acp-cursor / default` 等 `CLI default` 选项保留，表示沿用 CLI 当前模型。

已选模型携带 CLI 公布的说明、输入能力和已知容量。原选择器显示 ACP、图片能力和已知上下文标签，设置页展示详细信息；未公布的上下文、输出上限或价格不按名称推测。更新后在 **ACP 工作台** 刷新一次模型即可补齐信息，已保存的勾选列表不变。

模型公布可调思考强度时，可直接使用原选择器的强度控件。插件在发送任务前设置标准 `thought_level`，或选择同模型、其他参数相同的已公布 Cursor 变体。不会拼接未公布的模型 ID；设置失败不发送提示词。`CLI default` 仅沿用 CLI 当前配置，不提供独立强度覆盖。

Agent 公布的命令显示在执行记录的 **CLI 命令** 区域。此处提交的命令进入原生用户消息，但不会误触发 DSH 的同名斜杠命令。原输入框中的 DSH 命令保持原行为。

## 由 DSH 委派

保留普通 DSH 模型，使用 `subagent_cursor`、`subagent_antigravity` 或 `subagent_acp_claude_code`。后者使用 ACP，不占用官方非 ACP 工具 `subagent_claude_code` 的名称。三个工具均通过官方子代理工具创建具名、可续聊的原生子任务，不是一次性进程回执。

- 使用原生 `send_message` 续聊同一个子任务。
- 父会话输入框下方优先显示等你回应和进行中的子任务。审批卡片不用展开轨迹即可回答；已安静的子任务收在「其他子任务」，可以打开原会话或单独查看轨迹。
- 原生子代理树和结果交付机制保持不变。
- 插件不修改保存的预设或工具选择；如工具未显示，在原工具选择器中启用。

直接使用 ACP 引擎时，CLI 仍使用自己的工具，不自动获得 DSH 工具或 MCP。需要 DSH 编排时，使用委派模式。

## 历史与附件

一个 DSH 会话与一个提供方对应一个远端会话。连续输入复用远端上下文；分叉使用独立远端会话。在普通模型上完成的工作被标为历史补充，不作为新任务重发。

断开、原生会话重新打开和冷子任务续聊优先使用 CLI 公布的 `session/resume`，省去重播历史；只支持 `session/load` 的 CLI 仍可恢复。两者均不支持时明确报错。Host 重启、刷新页面和打开设置不会自动重发任务。**新建外部上下文** 只退役旧绑定，保留 DSH 消息及旧记录。

当前图片按 CLI 能力转发，返回图片使用 DSH 附件存储。普通文件通常作为 DSH 提供的只读本机路径交给 CLI。历史附件只在文本交接中保留说明。二进制输出等未映射内容保留在原始事件中。

## 设置、范围与数据

工作台默认打开 **活动**：等你回应、进行中、需查看的任务优先，归档和退役记录在「历史」。可按提供方、名称、目录或会话 ID 搜索。打开记录先处理审批，也可直接回到原会话；缺少直接父级地址的旧子任务可打开所属会话树。**提供方** 页负责编辑、模型选择、能力检查和会话导入。

ACP 路由不承担通用标题生成、DSH 压缩等辅助补全。需要这些功能时使用普通 DSH 模型或独立辅助模型配置。高级兼容工具 `acp_workbench` 不是原生委派入口，也不能代替人类审批；绑定到 DSH 会话的记录对它只读。

CLI 对提问或配置返回错误（需要登录、额度不足、模式不可用等）时，只有该轮或该设置失败，连接保留；进程退出等传输故障才断开。无法存入附件的返回图片改为指向原始事件的说明，不中断本轮。

原生消息由 DSH 保存，外部轨迹保存在 `acp_workbench` 存储域，目前不自动裁剪。提示词和人工决定在转发前持久化；异常退出仍可能损失尚未刷盘的流式尾部。

不新增远程中继、移动端、独立终端、自动 worktree 或另一套 IDE。已有 DSH 工作区、Git 和终端设施不被替换。
