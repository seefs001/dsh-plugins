<PluginFacts slug="acp-workbench" />

保留 DSH 的输入框、附件、消息时间线、停止按钮和子代理树。外部执行轨迹与人工交互进入当前会话，不再另开一套聊天工作台。默认提供 Cursor 和 Antigravity，也可配置其他本机 ACP CLI；不依赖 Paseo Hub 或 daemon。

## 安装

<InstallCommand slug="acp-workbench" />

先在终端安装并登录 CLI，再到侧栏 **ACP 设置** 的 **提供方** 页核对命令与参数。默认参数是 `["acp"]`。填写工作目录后，**检查能力** 只进行 initialize，不发送任务，结果以能力标签展示。

外部 CLI 使用自己的账号、计费、工具和文件权限，**不受 DSH 工具沙箱约束**。插件只能处理 CLI 实际发出的审批。不要在命令参数里填写密钥。

## 直接执行当前会话

1. 在原模型选择器中选择 ACP 提供方下的具体模型。
2. 如果尚未载入模型目录，到 **ACP 设置 → 提供方** 填写工作目录，点击 **刷新模型**，勾选需要显示的候选模型，再点击 **保存模型选择**。刷新只新建空 ACP 会话读取目录，不发送任务，也不自动加入主选择器。后续连接及配置更新不改变已选列表。
3. 使用原输入框提问、发送附件，在原时间线阅读回复。每轮的 **执行轨迹** 按发生顺序直接向下列出工具、计划、审批结果和 CLI 日志，结束后不再自动收起。单条工具的输入输出和 diff 可独立展开。
4. 权限请求、问题和计划审批以卡片出现在输入框下方。使用原停止按钮取消，已输出内容保留。
5. 模型和引擎切换统一使用原模型选择器。输入框下方不再显示引擎或模型配置；连接管理、新建外部上下文、模式与其他选项、CLI 命令和用量位于 **ACP 设置 → 执行记录**。

主选择器只显示已勾选保存的模型。选择具体模型后，插件先请求 CLI 切换模型，再发送本轮任务；切换失败不会发送任务。`acp-cursor / default` 等 `CLI default` 选项保留，表示沿用 CLI 当前模型。

已选模型携带 CLI 公布的说明、输入能力和已知容量。原选择器显示 ACP、图片能力和已知上下文标签，设置页展示详细信息；未公布的上下文、输出上限或价格不按名称推测。更新后在 **ACP 设置** 刷新一次模型即可补齐信息，已保存的勾选列表不变。

模型公布可调思考强度时，可直接使用原选择器的强度控件。插件在发送任务前设置标准 `thought_level`，或选择同模型、其他参数相同的已公布 Cursor 变体。不会拼接未公布的模型 ID；设置失败不发送提示词。`CLI default` 仅沿用 CLI 当前配置，不提供独立强度覆盖。

Agent 公布的命令显示在执行记录的 **CLI 命令** 区域。此处提交的命令进入原生用户消息，但不会误触发 DSH 的同名斜杠命令。原输入框中的 DSH 命令保持原行为。

## 由 DSH 委派

保留普通 DSH 模型，使用 `subagent_cursor` 或 `subagent_antigravity`。它们通过官方子代理工具创建具名、可续聊的原生子任务，不是一次性进程回执。

- 使用原生 `send_message` 续聊同一个子任务。
- 父会话输入框下方的 **ACP 子任务** 卡片显示状态和停止按钮；有待处理交互的子任务自动展开轨迹和交互卡片。
- 原生子代理树和结果交付机制保持不变。
- 插件不修改保存的预设或工具选择；如工具未显示，在原工具选择器中启用。

直接使用 ACP 引擎时，CLI 仍使用自己的工具，不自动获得 DSH 工具或 MCP。需要 DSH 编排时，使用委派模式。

## 历史与附件

一个 DSH 会话与一个提供方对应一个远端会话。连续输入复用远端上下文；分叉使用独立远端会话。在普通模型上完成的工作被标为历史补充，不作为新任务重发。

断开、原生会话重新打开和冷子任务续聊使用 CLI 的 loadSession 能力。不支持时明确报错。Host 重启、刷新页面和打开设置不会自动重发任务。**新建外部上下文** 只退役旧绑定，保留 DSH 消息及旧记录。

当前图片按 CLI 能力转发，返回图片使用 DSH 附件存储。普通文件通常作为 DSH 提供的只读本机路径交给 CLI。历史附件只在文本交接中保留说明。二进制输出等未映射内容保留在原始事件中。

## 设置、范围与数据

设置页分 **提供方**（编辑、刷新模型、能力检查、会话发现与导入）和 **执行记录**（搜索、归档筛选、详情、改名、连接/断开、配置、时间线与原始事件）两页。CLI 未上报的模型配置、用量或工具输出不会被编造；用量不是账号剩余额度。Cursor 私有模型目录扩展尚未接入。

ACP 路由不承担通用标题生成、DSH 压缩等辅助补全。需要这些功能时使用普通 DSH 模型或独立辅助模型配置。高级兼容工具 `acp_workbench` 不是原生委派入口，也不能代替人类审批；绑定到 DSH 会话的记录对它只读。

CLI 对提问或配置返回错误（需要登录、额度不足、模式不可用等）时，只有该轮或该设置失败，连接保留；进程退出等传输故障才断开。无法存入附件的返回图片改为指向原始事件的说明，不中断本轮。

原生消息由 DSH 保存，外部轨迹保存在 `acp_workbench` 存储域，目前不自动裁剪。提示词和人工决定在转发前持久化；异常退出仍可能损失尚未刷盘的流式尾部。

不新增远程中继、移动端、独立终端、自动 worktree 或另一套 IDE。已有 DSH 工作区、Git 和终端设施不被替换。
