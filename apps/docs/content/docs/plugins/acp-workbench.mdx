<PluginFacts slug="acp-workbench" />

`dsh-acp-workbench` 把本机 ACP（Agent Client Protocol）CLI 接入 DeepSeek Harness（DSH），让你继续使用原有的输入框、附件、消息时间线、停止按钮和子代理树。默认预设 **Cursor**、**Antigravity** 和 **Claude Code**，也可自由添加其他兼容 ACP v1 的本机 CLI。

## 使用方式

| 入口 | 怎么启动 | 适用场景 |
| --- | --- | --- |
| **会话内直接执行** | 在模型选择器选用 `acp-*` 提供方下的模型 | 把当前 DSH 会话交给 Cursor / Antigravity / Claude Code 直接执行 |
| **跨引擎双向委派** | 原生 DSH 与 ACP CLI 均使用聚合工具 `spawn_agent` / `list_providers` / `send_message` / `list_agents` / `read_agent_result` / `interrupt_agent` | 任意方向互相派发任务、按需开独立 Worktree、完成后自动回流唤醒，并在 DSH 原生顶栏切换器、右侧会话面板与分屏中统一查看 |
| **ACP 工作台（侧栏）** | 打开左侧栏 **ACP 工作台** | 配置本机 CLI 提供方、查看订阅与配额用量、检测协议能力，以及拉取和筛选主模型选择器中显示的模型 |

<Callout type="warn" title="外部 CLI 运行在 DSH 沙箱之外">
外部 CLI 使用自己的登录账号、计费、工具集与文件权限，不受 DSH 工具沙箱限制。插件会展示并转发 CLI 发来的审批与交互请求；请勿把密钥或令牌写入命令行参数。
</Callout>

## 安装与准备

<Steps>
<Step>

### 安装并登录本机 CLI

在终端完成目标 CLI 的安装与登录：

| 预设提供方 / 模板 | 默认可执行文件 | 默认参数 | 说明 |
| --- | --- | --- | --- |
| Cursor（`cursor`） | `cursor-agent`（优先 `~/.local/bin/` 或 `~/.bun/bin/`，否则取 `PATH`） | `["acp"]` | 默认预置 |
| Antigravity（`antigravity`） | `agy` | `["acp"]` | 默认预置 |
| Claude Code（`claude-code`） | `claude-agent-acp` | `[]` | 默认预置 |
| Codex（`codex`） | `codex-acp` | `[]` | 新增/配置模板 |
| Gemini CLI（`gemini`） | `gemini` | `["--acp"]` | 新增/配置模板 |
| OpenCode（`opencode`） | `opencode` | `["acp"]` | 新增/配置模板 |
| GitHub Copilot（`copilot`） | `copilot` | `["--acp"]` | 新增/配置模板 |

</Step>
<Step>

### 安装插件

<InstallCommand slug="acp-workbench" />

插件会自动注册 `acp-*` 模型路由、聚合跨引擎委派工具（`spawn_agent`、`list_providers`、`read_agent_result`），并在连接外部 ACP CLI 时自动注入本机 Session-scoped MCP 桥接（`http` 优先，不支持时自动回退 `stdio`）。

</Step>
<Step>

### 检查能力并筛选模型

打开左侧栏 **ACP 工作台**：

1. 在左侧选择预设提供方，或点击顶部 **新增提供方** 从内置模板一键填入常见 ACP CLI 的命令与参数（已有同名 ID 时自动避重）。
2. 在右侧顶部点击 **检查能力** 运行 ACP `initialize`，查看协议版本、登录方式与支持的能力；按需展开 **CLI 配置** 修改命令、参数或探测工作目录。
3. 点击 **刷新模型** 拉取可用模型及上下文、思考强度、Fast 等元信息（默认全部显示，可按搜索词与能力标签筛选并隐藏不需要的模型，确认后点击保存）。

</Step>
</Steps>

## 会话内直接执行

选中 `acp-*` 模型后，照常在 DSH 输入框发消息、附带图片/文件或点击停止即可。

<Tabs items={['模型与控制', '执行轨迹与卡片', '接续与复制 CLI 历史', '审批、提问与用量']}>
<Tab value="模型与控制">

### 模型、思考强度与 CLI 设置

- **模型与快捷属性**：模型选择器显示所有可见模型及 `CLI default`（沿用 CLI 当前模型），并支持逐模型思考强度（含将双思考项的 `Off` 合并进强度选择）。输入框右侧工具栏根据当前模型动态提供 `Mode`（Agent / Plan / Ask）、`Context`（如 300K / 1M）与 `Fast` 闪电开关；顶层会话按提供方（及适用模型）自动持久化所选模式与模型选项，新建会话与 Host 重启后自动沿用（不影响子代理）。若 CLI 拒绝切换则中止本次发送。
- **CLI 设置浮层**：在模型菜单点击 **CLI 设置**，可在输入框上方弹出浮动面板：
  - 实时修改 CLI 公布的模式与配置项；
  - 快捷打开右侧工作区面板（文件 / Git 改动 / 新建终端）；
  - 查看连接状态、仅连接、手动执行 CLI 命令，或接续/复制 CLI 历史会话。

### `/cli:` 命令补全

连接空闲时，在输入框行首输入 `/` 可从 CLI 分组选择 `/cli:<命令>`。补全参数并发送后，会按 `/名称 参数` 交给外部 CLI（仅支持纯文本参数；草稿重载或命令表更新后重新选择即可）。

</Tab>
<Tab value="执行轨迹与卡片">

### 执行轨迹与回复折叠

每轮回答旁的 **执行轨迹** 在运行时默认展开，工具调用、命令和结果会随 CLI 更新实时补入同一行；重开历史会话时默认折叠为状态、调用数和改动文件数。ACP 轮次结束后，回复末尾还提供 **收起结果 / 展开结果** 按钮（按浏览器记住状态，页内查找命中时自动展开）。

- **概览 / 逐条视图**：**概览** 会把连续完成的读取、搜索与网页查询合并为查阅摘要，运行中、失败、审批、命令和编辑仍单列。
- **写入与多文件补丁**：区分 **写入文件**（可切换查看写入正文与补丁）与 **编辑文件**；多文件补丁支持按文件筛选，并标注来源阶段（启动预览 / 审批请求 / 更新 / 完成 / 失败）。
- **命令输出**：实时展示流式输出（保留末尾 32 Ki 字符）与退出码/信号；工具完成时若另有汇总输出，可按需切换查看。
- **MCP 与网页工具**：MCP 调用标明服务与工具名，支持展开参数与结构化表格；网页工具区分 **网页搜索**、**抓取网页** 与 **页内查找**，展示查询词、域名规则与来源列表。
- **CLI 内部子任务**：Claude ACP 上报父调用 ID 时，可切入只读的 **查看子任务** 视图追踪其调用、进展与审批，支持多级下钻并一键返回 **完整轨迹**。
- **计划与上下文压缩**：展示任务清单、方案 Markdown 原文及 **CLI 上下文压缩** 摘要与前后 token 数。

</Tab>
<Tab value="接续与复制 CLI 历史">

### 接续 CLI 旧会话

首条消息前，从模型菜单打开 **CLI 设置 → 接续 CLI 会话**：

1. 插件按当前会话工作目录调用 `session/list` 列出可接续的历史记录。
2. 点击 **在这里接续** 连接旧上下文，下一条消息直接接在该 CLI 线程后继续；如果该会话已绑定其他 DSH 会话，则直接跳转原会话。
3. CLI 回放的前文可在设置面板按需展开查看。

### 从副本继续

想保留原对话并尝试另一条路线时：

1. 在同一工作目录新建一个未绑定的 DSH 会话，选中同一提供方。
2. 打开 **CLI 设置 → 接续 CLI 会话**，在目标记录旁点击 **从副本继续**（需 CLI 支持 `session/list`、`session/fork` 与恢复能力）。
3. 插件会复制 CLI 最新已保存历史生成独立外部上下文，原会话不受影响。

</Tab>
<Tab value="审批、提问与用量">

### 权限、表单与计划审批

- **审批卡片**：工具权限请求、提问与计划审批显示在输入框上方，标明调用 ID、工作目录与各选项的作用范围（单次或后续沿用），并可展开 **查看最初的工具调用** 核对上下文。
- **权限控制边界**：外部 CLI 运行在 DSH 沙箱之外；切换到 ACP 模型时会自动隐藏输入框左下角的 DSH 原生权限预设控件，审批与权限策略完全交由各 CLI 自身的模式与配置处理，不再根据 DSH 预设自动放行。
- **CLI 表单提问**：Claude Code 的 `AskUserQuestion`（`elicitation/create`）以原生表单呈现单选、多选与补充输入，请勿在表单中填写密码或令牌。

### 提醒与用量

- **CLI 会话提醒**：轮次内的提醒留在轨迹中；连接时或轮次间的提醒显示在输入框下方（保留最近 8 条）。
- **上下文与累计用量**：输入框下方显示当前连接上次上报的上下文窗口占用与累计费用；每轮轨迹末尾保留该轮结束时的会话累计 token。

</Tab>
</Tabs>

## 跨引擎双向委派（DSH ↔ ACP 任意互调）

原生 DSH 与所有已配置的 ACP CLI（Cursor、Antigravity、Claude Code 等）共享同一套聚合工具契约（外部 CLI 通过本机 Session-scoped MCP 自动注入）：

- **`list_providers` / `spawn_agent`**：发现可用原生 DSH 与 ACP 引擎、模型及模式，按需指定 `provider`、`model`、`modeId`、`reasoningEffort` 与 `isolation: "worktree"`（自动创建独立 Git 工作树分支，不改动父会话目录），创建真正的 DSH 可续聊子会话。
- **自动回流与静默批合并**：子任务完成后结果自动投递至父会话收件箱；当父会话为 ACP 引擎且有多个并行子任务先后完成时，在 2 秒静默窗口内自动批合并唤醒，避免重复轮次；`send_message` 支持 `followup`、`steer`（支持 `_session/steering` 时实时引导）与 `interrupt`。
- **深度融入原生 UI**：所有跨引擎子任务自动进入 DSH 原生顶栏面包屑树、**顶栏子智能体快速切换器**（悬停或点击即可查看原生与 ACP 子智能体实时状态与待回应数，一键主视图或右侧分屏打开）、右侧会话面板的 **ACP 子智能体** 分栏（展示当前工具、模型、回复预览、耗时与上下文占用，支持主视图/分屏打开及一键停止）以及右侧分屏 `SidebarChat`；`spawn_agent` 调用行支持一键 **右侧分屏打开**；输入框上方 Dock 收紧为仅在后代子任务等待审批或提问时浮出，并在右上角面板按钮亮起待回应指示点。

## 提供方与模型目录（ACP 工作台）

侧栏 **ACP 工作台** 采用左侧提供方列表 + 右侧模型目录主区布局：

- **提供方概览与预设模板**：左侧显示各 CLI 提供方的可见/总模型数、已缓存订阅档位或峰值用量百分比、命令行预览与活跃连接状态；顶部 **新增提供方** 与 **CLI 配置** 内置常见 ACP CLI 预设模板，可一键填入默认命令与参数。
- **订阅与用量卡片**：展示各提供方的登录状态、账号与订阅档位、按需刷新的配额窗口进度条与重置时间（Claude Code 通过 ACP `/usage` 与 `_claude/rateLimit`、Codex 通过 `codex app-server`、Cursor 通过 CLI `about`/`status`、Antigravity 通过 ACP 档位元信息），以及基于 DSH 本地记录的近 24 小时、近 7 天与累计会话/轮次统计。
- **模型目录筛选与可见性管理**：支持按名称/ID 搜索与 `全部 / 已显示 / 已隐藏 / 思考 / Fast / 多上下文` 标签过滤，直观展示思考强度、上下文窗口、Fast、图片输入与输出上限，支持全部显示/全部隐藏与未保存更改提示。
- **按需展开的配置与诊断**：命令行参数与探测目录收纳在可折叠的 **CLI 配置** 面板，协议能力与原始 JSON 诊断收纳在可关闭的 **检查能力** 面板。

## 上下文交接与数据存储

- **会话绑定与交接**：每个 DSH 会话与每个 ACP 提供方一一绑定，分叉会话会创建独立远端上下文。首次使用或从普通 DSH 模型切回时自动交接未同步的历史文本（上限 **200,000 字符**，超限报错）。
- **重连与恢复**：断线重连或冷子任务续聊优先调用 `session/resume`，不支持时回退 `session/load`。Host 重启后中断的运行标记为 `interrupted`，需人工决定是否继续。
- **附件**：CLI 支持图片时转发当前输入图片，返回图片写入 DSH 附件系统；普通文件通过本机只读路径或 resource link 传递。
- **存储位置**：DSH 核心保存原生会话消息；外部绑定、配置与原始事件分块保存在 Host 的 `acp_workbench` storage domain（大 diff 自动窗口裁剪，并按保留天数与总容量上限自动清理旧分块）。
- **辅助补全回退与上下文过滤**：转发给外部 CLI 时自动跳过 DSH 宿主专属的 `skill` 目录提醒并去重 Nowledge Mem 快照；第三方功能向 `acp-*` 发起带 `purpose` 的辅助补全（如 Timeline 周期摘要）时，可通过 `config.utilityProvider` / `config.utilityModel` / `config.utilityReasoningEffort`（或 `DSH_ACP_UTILITY_*` 环境变量）透明回退到普通文本模型。

更多表结构与模块划分见 [packages/acp-workbench/README.md](https://github.com/seefs001/dsh-plugins/tree/main/packages/acp-workbench/README.md)。
