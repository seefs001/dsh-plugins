在输入框里按 `#` 选择模型后，插件会插入一个带推理强度和快速模式标记的模型标签（例如 `#GPT-6.1 Sol · xhigh ⚡`），让你可以在提示词里明确点名让子代理使用哪个模型，而不必手动拼写 provider 和参数。

## 使用方法

<Steps>
<Step>

### 插入模型标签

在输入框行首或空格后键入 `#`，继续输入模型名或 provider 名称过滤，按回车、Tab 或点击菜单项插入标签。按退格键可一次删掉整块标签；复制标签时得到 `#provider/model`。

</Step>
<Step>

### 发送时的真实内容

标签发出时会展开为结构化文本：

```text
#model(provider=openai, model=gpt-6.1-sol, reasoning_effort=xhigh, service_tier=priority)
```

历史消息气泡里同样会还原为带强度与 `⚡` 图标的胶囊标签。

</Step>
</Steps>

## 标签状态从哪里来

- **推理强度**：Host 监听顶层会话的 `model/selection` 事件，按 `provider/model` 记录你最近选用的推理强度（子代理会话的选择不会覆盖主会话记录），并写入 profile 的 `cordis.patch.yml`（`efforts` 字段）。
- **快速模式（⚡）**：同时安装了 [快速模式](/docs/plugins/service-tier) 时，标签会自动同步该模型是否处于 `priority` 或 `ultrafast` 档位；未安装也能正常使用。

## 边界说明

- 插入 `#` 引用**不会切换当前会话自己的模型**，只向模型传递文本引用。
- 从历史消息复制再粘贴回输入框时，不会自动变成可删除的交互标签，需重新通过 `#` 插入。
- Host 只暴露只读的 `/model-reference/state` 接口（需 owner 鉴权）。
