在输入框里输入 `#`，选一个模型，它会像 `@` 引用文件或会话一样变成一个标签。标签带上这个模型上次使用的推理强度；装了 [快速模式](/docs/plugins/service-tier) 并对该模型开启 ⚡ 时，也会带上快速模式。这样就可以写“让 #GPT-6.1 Sol · xhigh ⚡ 在子代理里审查这个 diff”。

## 使用

| 按键 | 作用 |
| --- | --- |
| `#` 加文字 | 打开选择器，按模型名、模型 ID、provider 名或 provider ID 过滤。每个词都要匹配，`/` 和空格用来分词 |
| `↑` / `↓` | 移动高亮 |
| `Enter` / `Tab` | 插入高亮的模型 |
| `Esc` | 关闭这次查询的选择器 |

复制标签时，剪贴板里是 `#provider/model`。

在输入框的模型选择器或 `/model` 里切换模型时，插件会恢复该模型保存的推理强度。对同一个模型明确选择“默认”会清除保存的强度。保存的强度该模型已不支持时，回到模型自己的默认值。

## 模型看到什么

标签在提示词里序列化成：

```text
#model(provider=responses, model=gpt-6.1-sol, reasoning_effort=xhigh, service_tier=priority)
```

这是一段写给模型的文字，不会切换当前会话的模型。模型是否按这个引用去启动子代理，取决于你的提示和可用的工具。

## 配置

```yaml
- id: model-reference
  config:
    efforts:
      responses/gpt-6.1-sol: xhigh
```

`efforts` 记录每个 `provider/model` 上次的推理强度，由插件自动写入，一般不需要手改。只记录顶层会话的选择，子代理会话的选择不会覆盖它。

## 原理

| 部分 | 作用 |
| --- | --- |
| Host（`lib/index.js`） | 监听顶层会话的 `model/selection` 事件，按 `provider/model` 保存推理强度，并通过 `GET /model-reference/state` 提供给浏览器。这个路由和其他 Web API 使用同样的认证 |
| Web（`lib/client.js`） | 在 `conversation.input.overlay` 渲染 `#` 菜单，并在 input-trigger 管线里注册标签编解码 |
