<PluginFacts slug="model-reference" />

在输入框键入 `#` 选择模型后，插件会插入带推理强度与快速模式标记的引用标签（例如 `#GPT-6.1 Sol · High ⚡`），方便在提示词里直接指定子代理要用的模型和档位。

## 使用方法

<Steps>
<Step>

### 插入标签

在输入框行首或空格后键入 `#`，继续输入模型名或 provider 名称筛选，按回车、Tab 或点击菜单项插入。按退格键可整块删除，复制标签得到 `#provider/model`。

</Step>
<Step>

### 发送与回显

发出时标签会展开为结构化文本：

```text
#model(provider=openai, model=gpt-6.1-sol, reasoning_effort=high, service_tier=priority)
```

历史消息气泡中会自动还原为同款胶囊标签，悬停可查看完整文本。

</Step>
</Steps>

## 状态记忆与联动

- **推理强度记忆**：Host 监听顶层会话的 `model/selection` 事件（忽略子代理），按 `provider/model` 记录最后选用的推理强度并保存到 `cordis.patch.yml` 的 `efforts` 字段；切换回该模型或插入 `#` 标签时自动恢复。
- **快速模式联动**：同时安装 [快速模式](/docs/plugins/service-tier) 时，标签会自动同步该模型的 `priority` 或 `ultrafast` 档位。
- 插入 `#` 引用只向消息写入文本，不会切换当前会话的模型。
