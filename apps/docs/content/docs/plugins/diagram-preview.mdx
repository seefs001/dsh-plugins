---

<PluginFacts slug="diagram-preview" />

回复流式输出期间显示原代码，完成后自动渲染为图表。每张图支持 **预览 / 代码** 切换、**小图 / 中图 / 大图** 尺寸调整、在工具栏下载 **SVG**，以及点击打开最高 400% 的大图缩放弹窗（支持 **复制 PNG**、**下载 PNG** 与 **下载 SVG**）；语法有误时提示原因并保留原代码。

## 支持的代码块标签

| 代码块标签 | 内容 |
| --- | --- |
| `mermaid`、`mmd` | Mermaid 图表（流程图、时序图、ER 图、甘特图等） |
| `dot`、`graphviz` | Graphviz DOT 图 |
| `echarts` | JSON 格式的 ECharts option |
| `svg` | 带 SVG 命名空间的独立矢量图 |

渲染库随插件按需在浏览器本地沙箱加载，不向外发送图表内容；输出为静态图片，不运行脚本，也不支持交互与外链资源。
