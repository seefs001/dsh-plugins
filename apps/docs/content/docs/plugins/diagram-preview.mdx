---
title: 图表预览
description: 把对话里的 Mermaid、Graphviz、ECharts 和 SVG 代码块显示成图，随时切回源码。
---

<PluginFacts slug="diagram-preview" />

回复生成时显示原代码，生成完毕后自动显示图表。每张图右上角的「代码」可以切回原生代码块并复制源码，「预览」切回图表。语法有误时会显示原因并保留原代码。

每张图可以单独选「小图 / 中图 / 大图」调整它在消息里的大小。点击图表或「查看大图」打开适应窗口的预览；放大到最高 400% 后可滚动查看细节。按 Esc 或「关闭」返回。

| 代码块标签 | 内容 |
| --- | --- |
| `mermaid`、`mmd` | 流程图、时序图、ER 图、甘特图等 Mermaid 图表 |
| `dot`、`graphviz` | DOT 关系图 |
| `echarts` | JSON 格式的 ECharts option，包括柱状图、折线图、饼图等 |
| `svg` | 带 SVG 命名空间的独立矢量图 |

例如，让模型「用 Mermaid 画一张下单流程图，放在带 mermaid 标签的代码块里」。只有明确标记的代码块会被替换，普通代码、JSON 和原生公式不受影响。

## 安装

<InstallCommand slug="diagram-preview" />

渲染器随插件提供，按需在浏览器本地加载，不向第三方发送图表文本。预览是图片，不运行图表中的脚本，不支持交互与外链素材。
