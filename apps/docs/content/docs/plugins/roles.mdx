<PluginFacts slug="roles" />

角色由一段详细提示词和它自带的技能组成。在输入框的模型菜单里为会话选择角色后，Agent 从下一步开始按这个角色工作。

## 安装

<InstallCommand slug="roles" />

需要 `@deepseek-ai/dsh-storage-domain` 和 `@deepseek-ai/dsh-system-prompt`；角色技能还需要 `@deepseek-ai/dsh-skill` 和 `@deepseek-ai/dsh-tool-skill`。默认 profile 都已包含。

## 选择角色

- 打开输入框的模型菜单，在 **模型** 和 **推理强度** 下面有一行 **角色**。点开后选择一个角色，或选 **无** 清除。
- 当前角色以标签形式显示在输入框左侧。点标签，或列表里的 **管理角色…**，打开角色管理页。
- 每个会话的角色各自独立，新会话默认无角色。子代理会话不显示这一行。
- 切换从下一次模型请求开始生效，正在运行的一步保持原来的提示词。

## 管理角色

从侧边栏的 **角色** 打开独立管理页；本插件在 **插件** 页面里的配置区也提供入口：

- 左栏按菜单顺序列出角色，显示技能数和正在使用的会话数。
- 名称、emoji 图标和简介直接编辑。下方分为 **提示词**、**技能**、**模型看到的内容**，预览包含未保存修改。
- 底部固定保存栏提供 **保存**（⌘S / Ctrl+S）和 **放弃修改**。切换角色或离开面板会保留当前页面内的草稿，刷新页面则不会保留。新角色点击 **创建角色** 后才写入。
- **更多操作** 包含复制、上移、下移、恢复内置内容和删除。复制包含当前草稿。删除角色后，使用它的会话回到无角色。
- 未保存标记、字段错误和外部修改提醒显示当前编辑状态。
- 自带四个内置角色：代码审查员、架构师、调试专家、技术写作，每个都有详细提示词和一到两个技能。可以随意修改；**恢复内置内容** 还原单个角色，**恢复内置角色** 加回被删掉的内置角色。

上限：100 个已保存角色，每个角色 20 个自带技能和 20 个本地技能引用，提示词 40,000 字，单个自带技能 60,000 字。

### 引用本地技能

在 **技能 → 引用本地技能** 中搜索并勾选已有技能。列表来自 DSH 原生技能目录，包含已配置的用户、自定义和内置文件系统技能。填写项目目录并点击 **读取技能目录**，可加入该项目的技能。

角色只在 `localSkills` 中保存名称，不复制或修改文件。使用时由原生 `skill` 工具按会话的项目目录解析，技能资源目录和本地修改保持有效。引用在会话目录里不可用时，角色提示词要求 Agent 说明缺失，不编造技能内容。引用不会隐藏或限制会话里的其他技能。同一角色不能同时引用和内嵌同名技能。

下方的 **角色自带技能** 则把 Markdown 内容保存在角色本身，可直接编辑。

## 模型看到什么

- **提示词**：角色加在系统提示词里，位于部署 persona 之后、DSH 自身指引之前，格式是 `# Active role: <名称>`，接着是你的提示词和角色技能的名称，并说明对话中用户的明确要求优先。
- **技能**：角色技能由注册在每个 Agent 自己 scope 上的技能 provider 提供，只出现在使用该角色的会话的 `skill` 目录里，用 `skill` 工具按需加载。技能名用 kebab-case；与项目或用户技能重名时，项目和用户技能优先。角色技能没有文件，内容里不要引用相对路径。

切换角色会改变系统提示词，下一次请求的 provider 缓存命中会下降。

## Agent 工具

Host 注册 `roles` 工具，操作与界面相同：`list`、`get`、`catalog`、`preview`、`create`、`update`、`duplicate`、`delete`、`move`、`select`、`reset`、`restore_builtins`。`select` 作用于调用它的会话。工具描述要求 Agent 只在用户要求时切换或修改角色。

`catalog {cwd?}` 返回本地技能元数据，不读取正文。`create` / `update` 的角色字段支持 `localSkills: ["skill-name"]`。`preview {role}` 预览草稿提示词，不保存。

## 数据

角色和每个会话的角色选择保存在 Host 的 `roles` storage domain。使用默认 `json` 后端时，文件是 `~/.dsh/storages/roles.json`。角色已不存在的选择会被清理，最多保留 2,000 条会话选择。

## HTTP

| 路由 | 方法 | 用途 |
| --- | --- | --- |
| `/roles/state` | GET | 全部角色和会话选择 |
| `/roles/op` | POST | 执行一个操作，参数与工具相同，`select` 需带 `sessionId` |
| `/roles/events` | GET | 每次改动后推送完整状态的 SSE |

所有路由都走 Host 的常规连接检查。
