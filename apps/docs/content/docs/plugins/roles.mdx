<PluginFacts slug="roles" />

将常用的工作身份（详细提示词 + 专属技能 + 本地技能引用）整理为可复用的 **角色**，在任意主会话的模型菜单里按需切换，从下一步请求起直接生效。

## 安装

<InstallCommand slug="roles" />

需要 `@deepseek-ai/dsh-storage-domain`（默认 profile 已包含）。

## 内置角色

首次启用时会自动初始化 4 个内置角色，你可以直接修改、复制，或在需要时重置/恢复：

| 角色 | 适用场景 | 自带技能 |
| --- | --- | --- |
| 🔍 **代码审查员**（`code-reviewer`） | 按正确性、安全、可维护性逐项审查改动 | `review-checklist`、`security-review` |
| 🏛️ **架构师**（`architect`） | 厘清约束与取舍，输出模块边界与演进方案 | `adr-writing`、`interface-design` |
| 🐛 **调试专家**（`debugger`） | 复现问题、定位根因与最小修复 | `debug-loop` |
| ✍️ **技术写作**（`tech-writer`） | 面向读者写清结论、步骤与使用边界 | `doc-structure` |

## 使用方法

<Tabs items={['按会话切换', '在侧栏管理角色', 'Agent 工具']}>
<Tab value="按会话切换">

1. 打开任意主会话，点击输入框底部的模型菜单。
2. 在 **角色** 一行选择目标角色（或切回 **不使用角色**）。
3. 从下一步模型调用起生效：
   - 角色提示词通过全局 `systemPrompt.section`（`order: 5`）拼入当前会话的系统提示词；
   - 角色自带技能仅对该会话自己的 `skill` 注册表可见，其他会话不会混入。

</Tab>
<Tab value="在侧栏管理角色">

打开左侧栏 **角色** 页面，支持跨浏览器实时同步（SSE）：

- **编辑角色提示词**：Markdown 格式，单角色上限 40,000 字符。
- **管理角色技能**：
  - **本地技能引用**：按名称引用本机已发现的技能（每角色最多 20 个），不复制文件，也不隐藏会话原有其他技能。
  - **角色自带技能**：在角色内部编写 kebab-case 命名的技能说明（每角色最多 20 个，单技能上限 60,000 字符），适合放角色专用的检查清单。
- **预览**：在「预览」标签页实时查看最终注入系统提示词的文本与技能清单。
- **排序与恢复**：在列表右上角菜单可复制、上移/下移、重置单个内置角色或删除角色；支持一键恢复已删除的内置角色。

</Tab>
<Tab value="Agent 工具">

插件注册了 `roles` 工具，支持 `list`、`get`、`catalog`、`preview`、`create`、`update`、`duplicate`、`delete`、`move`、`select`、`reset` 与 `restore_builtins`。工具描述约束仅在用户明确要求时才修改或切换角色。

</Tab>
</Tabs>

## 数据与上限

- 数据保存在 Host 的 `roles` storage domain（`global` 表存角色库，`sessions` 表存会话选择）。
- 角色库最多保存 **100** 个角色；会话选择记录最多保留最近 **2000** 条，被删除角色的会话关联会自动清理。
- 角色自带技能是内存中的虚拟技能，没有磁盘资源目录，编写指令时请勿引用相对文件路径。
