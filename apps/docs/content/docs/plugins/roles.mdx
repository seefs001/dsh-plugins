<PluginFacts slug="roles" />

把常用的工作身份（系统提示词 + 专属技能 + 本地技能引用）整理为可复用的**角色**，在任意主会话的模型菜单中按需切换，从下一次模型请求起生效。

## 安装

<InstallCommand slug="roles" />

依赖 `@deepseek-ai/dsh-storage-domain`（默认 profile 已包含）。

## 内置角色

首次启用时会自动初始化 4 个内置角色，可直接编辑、复制、重置或一键恢复缺失项：

| 角色 | 适用场景 | 自带技能 |
| --- | --- | --- |
| 🔍 **代码审查员**（`code-reviewer`） | 按正确性、安全与可维护性审查改动 | `review-checklist`、`security-review` |
| 🏛️ **架构师**（`architect`） | 厘清约束与取舍，输出模块边界与演进方案 | `adr-writing`、`interface-design` |
| 🐛 **调试专家**（`debugger`） | 复现问题、定位根因与最小修复 | `debug-loop` |
| ✍️ **技术写作**（`tech-writer`） | 写清结论、步骤与使用边界 | `doc-structure` |

## 使用方法

<Tabs items={['按会话切换', '# 快捷引用', '侧栏管理', 'Agent 工具']}>
<Tab value="按会话切换">

1. 打开任意主会话，点击输入框底部的模型菜单。
2. 在**角色**一行选择目标角色（或切回**无**）。
3. 从下一步请求起生效：角色提示词通过 `systemPrompt.section`（`order: 5`）拼入系统提示词，角色自带技能仅对该会话可见。

</Tab>
<Tab value="# 快捷引用">

1. 在输入框行首或空格后键入 `#`，按角色名称、ID 或简介筛选，按回车、Tab 或点击插入引用标签（例如 `#🔍 代码审查员`）。
2. 发送时标签展开为 `#role(id=code-reviewer, name=代码审查员)`，历史消息气泡中自动还原为同款胶囊标签，悬停可查看完整文本；不切换当前会话角色。
3. 系统提示会附带一条引用说明，引导 Agent 按需通过 `roles` 工具（`get`）读取该角色的提示词与技能，适合临时指派角色或配置子代理。
4. 同时安装 [`# 引用模型`](/docs/plugins/model-reference) 时，角色与模型会合并显示在同一个 `#` 菜单中。

</Tab>
<Tab value="侧栏管理">

打开左侧栏**角色**面板（跨标签页通过 SSE 实时同步）：

- **提示词**：Markdown 格式，单角色上限 40,000 字符。
- **技能**：
  - **本地技能引用**：按名称引用本机已发现技能（每角色最多 20 个），不复制文件。
  - **角色自带技能**：在角色内编写 kebab-case 命名的虚拟技能（每角色最多 20 个，单技能上限 60,000 字符），无磁盘文件，请勿引用相对路径。
- **预览**：保存前实时查看拼装后的系统提示词与技能清单。
- **排序与恢复**：在右上角菜单支持复制、上移/下移、重置内置角色与删除，侧栏底部支持一键恢复已删除的内置角色。

</Tab>
<Tab value="Agent 工具">

插件注册 `roles` 工具，支持 `list`、`get`、`catalog`、`preview`、`create`、`update`、`duplicate`、`delete`、`move`、`select`、`reset` 与 `restore_builtins`。

</Tab>
</Tabs>

## 数据与上限

- 数据保存在 Host 的 `roles` storage domain（`global` 存角色库，`sessions` 存会话选择）。
- 角色库上限 **100** 个角色；会话选择最多保留最近 **2000** 条，删除角色后自动清理对应关联。
