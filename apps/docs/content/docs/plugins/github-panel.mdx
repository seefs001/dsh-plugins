<PluginFacts slug="github-panel" />

当会话的工作目录属于一个关联了 GitHub 远端的 Git 仓库时，在右侧会话面板自动添加 **GitHub** 分栏，展示仓库基本信息、打开中的 Pull Requests、Issues、近期 GitHub Actions 工作流运行和 Latest Release；非 GitHub 仓库或非 Git 目录自动隐藏。

<Callout type="info" title="依赖本机 GitHub CLI">
Host 端通过已登录的 `gh` CLI 读取数据（不依赖 Forge 套件，支持私有仓库与 GitHub Enterprise）。未登录时面板会提示 `gh auth login` 命令并支持一键复制。
</Callout>

## 主要功能

- **对话提及自动归集**：识别对话中出现的 GitHub 链接（Issue / PR / Actions Run）、`owner/repo#123` 及同仓库 `#123` / `PR #123` / `Issue #123`，批量解析实时状态（含已关闭和已合并项）并置顶显示在 **对话提及** 分组；跨仓库条目也可直接在右栏查看完整详情。
- **右侧会话面板分栏**：按原生行样式显示仓库概览、对话提及、打开中的 PR（含草稿与检查状态）、Issue、近期 Actions 运行（含状态点与分支）及最新发布，支持悬停详情卡与长列表折叠。
- **右侧边栏详情标签**：点击任意条目在右侧边栏打开 **GitHub** 标签页，查看 PR/Issue 的 Markdown 正文、标签、检查与评论，查看 Actions 各 Job 与步骤并一键重跑失败任务，或浏览最近提交与 Release 说明。
- **引用到对话输入框**：PR、Issue 与 Actions 运行均支持一键插入链接与标题到当前会话输入框（不自动发送）。
- **状态提醒**：当前分支最新 Actions 失败且面板收起时，会话标题栏面板开关显示红点提醒。

## 配置（可选）

默认支持 `github.com`。如需支持 GitHub Enterprise 实例，在 `cordis.patch.yml` 中增加 `hosts`：

```yaml
- id: github-panel
  name: dsh-github-panel
  config:
    hosts:
      - github.com
      - ghe.example.com
```
