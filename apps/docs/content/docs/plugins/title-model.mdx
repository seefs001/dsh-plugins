为会话标题生成单独指定一个更快或更便宜的模型，不改动主对话模型、标题提示词和触发时机。

<Callout type="info" title="前置条件">
需先在 DSH 设置中启用原生标题生成器（「首条消息标题」或「随对话更新标题」）。
</Callout>

## 安装

<InstallCommand slug="title-model" />

## 配置方式

### 界面配置

在 **Plugins** 页面打开 **dsh-title-model**，为已启用的标题生成器选择模型（或 **跟随会话**），点击 **保存** 即对后续生成的标题生效。

### Agent 工具

提供 `title_model` 工具：

- `action: "get"`：读取当前已启用的标题生成器与生效模型。
- `action: "set"`：成对传入 `provider` 与 `model`（同为空字符串时恢复 **跟随会话**）；有多个生成器时一并传 `generator` ID。

## 说明

配置直接写入原生标题生成器条目，仅作用于后续标题，停用插件不会还原。卸载前如需恢复默认，请先切回 **跟随会话** 并保存。
