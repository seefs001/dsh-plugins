<PluginFacts slug="title-model" />

为 DSH 的标题生成器单独选择模型，不改变主对话模型。支持原生首条消息标题，以及官方“随对话更新标题”。插件不会启用或替换标题生成器。

## 安装

<InstallCommand slug="title-model" />

需要已启用上述任一种原生标题生成器，以及 profile 的 config editor。

## 使用

1. 打开 **插件 → 标题模型**，查看当前已加载的标题生成器。
2. 从 Host 模型目录选择模型，点击 **保存**。配置对 Host 后续的标题请求生效，不会立即重新生成已有标题。
3. 选择 **跟随会话** 并保存，清除独立模型配置。
4. 在其他页面切换标题策略后，点击 **重新加载设置**。重新加载会放弃未保存的选择，两个生成器各自保留其配置。

模型暂时不可用时，页面保留已保存的模型标识并标记为“不可用”，仍可切回“跟随会话”。模型目录部分加载失败会显示提示，不影响选择已列出的模型。

## 配置与数据

插件通过 DSH config editor 修改原生标题生成器的 `provider` 和 `model` 字段，保留其他配置与 YAML 表达式。选择“跟随会话”会删除这两个字段，而不是写入空字符串。本插件没有独立 storage domain，也不保存凭据。

**禁用或移除本插件不会清除原生生成器已保存的模型。** 需要恢复会话模型时，请先重置并保存。

标题请求将当前策略所需的用户消息发送到所选 provider，可能产生独立费用。原生标题系统继续负责输入限制、超时、中止和请求记录。生成失败时保留原有标题，不会静默回退到其他 provider。

## Agent 工具

预设允许时，`title_model` 提供相同的 Host 操作：

- `action: "get"`：读取生成器 ID、策略与模型。
- `action: "set"`：指定生成器 ID、`provider` 和 `model`。仅有一个生成器时可以省略 ID。
- 两个字段都传空字符串，恢复跟随会话。

修改是 Host 级配置，不限于当前对话。

## 限制

- 手动固定的标题不变，已有标题不会立即重生成。
- 推理强度、标题提示词、生成频率和输入输出预算仍由原生生成器管理。
- 不支持自定义标题 provider；原生生成器未启用或加载失败时，需要先在原生配置中处理。
