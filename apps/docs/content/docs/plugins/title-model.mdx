<PluginFacts slug="title-model" />

让你把「生成会话标题」的后台请求路由到一个更快或更便宜的模型上，主对话的模型、标题提示词与生成时机保持完全不变。

<Callout type="info" title="需要先启用原生标题生成器">
本插件只改写已启用的标题生成器配置，不会替你开启标题生成。请先在 DSH 设置中启用「首条消息标题」或「随对话更新标题」。
</Callout>

## 配置方式

### 在 Plugins 页面设置

1. 打开 **Plugins → dsh-title-model**。
2. 页面会列出当前处于启用状态的标题生成器（`first-prompt` 与 `all-prompts`）。
3. 为对应生成器选择一个模型（或切回 **跟随会话**），点击 **保存** 即可对后续标题生效。

### 通过 Agent 工具设置

插件向模型暴露了 `title_model` 工具：

- `action: "get"`：读取当前已启用的标题生成器与生效模型。
- `action: "set"`：传入 `provider` 与 `model`（两者需成对设置，或同时传空字符串恢复 **跟随会话**），当存在多个生成器时需指定 `generator` ID。

## 数据与边界

- 配置直接写入原生标题生成器条目的 `config`（`provider`、`model`），停用本插件后设置仍然生效；如需恢复默认，请先切回 **跟随会话** 并保存。
- 只影响保存之后触发的标题请求，已有标题和手动固定的标题不会被改写。
- 发往所选模型服务的提示词仅包含标题生成器按规则抽取的内容，并可能产生对应模型服务的调用费用。
