<PluginFacts slug="recent-sessions" />

在输入框键入 `@` 引用历史会话时，将每个连续的会话区块按最近活动时间（`updatedAt`）从新到旧排序。

## 安装

<InstallCommand slug="recent-sessions" />

## 工作方式

- 包装 `@` 引用源（`reference`），解码每条会话的 `dsh-session:` 引用 ID，并按会话目录中的 `updatedAt` 做稳定降序排序。
- 同活动时间的条目保持原顺序；文件引用和其他非会话条目不变。
- 纯 Web 端生效，无需配置。
