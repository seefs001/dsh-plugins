<PluginFacts slug="recent-sessions" />

在输入框键入 `@` 引用历史会话时，默认列表可能按创建时间或目录分组排序。本插件把每个连续的会话区块按最近活动时间（`updatedAt`）从新到旧重新排列。

## 安装

<InstallCommand slug="recent-sessions" />

## 工作方式

- 自动包装 `@` 引用源（`reference`），解码每条会话的 `dsh-session:` 引用 ID，并对照实时会话目录的时间戳稳定排序。
- 同活动时间的条目保持原顺序；文件引用和其他非会话条目完全不动。
- 纯 Web 端生效，无需配置，也不保存额外状态。
