在输入框输入 `@` 引用会话时，会话按最后活动时间排序，最新的排在最前面。文件行和其他分组不受影响。

## 安装

<InstallCommand slug="recent-sessions" />

## 原理

只有 Web 部分，Host 入口是空的。

插件包装内置 `@` 来源（`dsh-client-ui-reference` 中名为 `reference` 的来源）的 `candidates()`。同一分组里连续的会话行按会话的 `updatedAt` 排序，时间相同时保持原顺序。停用插件会恢复原函数。

这个来源是异步注册的，插件每 500 ms 查找一次，30 秒后放弃。

## 兼容性

插件依赖 `dsh-client-ui-reference` 的内部约定：来源名 `reference`、`icon: 'session'` 的行结构，以及 `dsh-session:` 引用编码。DSH 改变这些约定后，插件不做任何事，不会报错。
