输入框旁的 **技能速查** 按钮打开当前会话的技能清单。不需要记住技能名称，也不用先调用技能才能看用途。

## 用法

1. 点击输入框旁的 **技能速查**。
2. 加宽的左侧列表用一句中文短说明展示技能的操作。可按名称、中文短说明、原始用途或适用场景搜索；右侧详情保留作者完整说明，窄屏时放在列表下方。
3. 点击置顶按钮收藏常用技能。默认置顶在前，各组按使用次数从高到低排列，次数相同时按名称排序。取消置顶不移除技能。
4. 点击 **写入 /技能名**，把命令和一个空格放到输入框开头，再补充具体需求。保留原有文字、引用片段和附件；写入成功后关闭弹窗，不自动发送消息或执行技能。

默认只显示 **仅限手动调用** 的技能，即 `modelInvocable: false`、Agent 不能自行加载的技能。勾选 **包含 Agent 可自动调用的技能**，可显示其余用户也能手动调用的技能。开关关闭时，置顶项也遵循过滤规则；没有仅限手动技能时，会提供显示其他技能的入口。

开关每次重新打开弹窗时恢复关闭，刷新目录则保留当前选择。隐藏不改变权限，也不表示隐藏项不能手动调用。仅供 Agent 调用的技能始终不在原生目录中。

## 数据与更新

清单来自 DSH 原生的会话技能目录 `skills/list`，跟随当前会话的工作区和 Agent 预设，不扫描固定目录。每次打开重新读取，也可以点击 **刷新**。

中文短说明保存在 Host 的 `~/.agents/skills/short-descriptions.zh.json`，格式是“技能名 -> 一句话说明”的扁平 JSON，由你自己维护、不随插件分发。文件不会往目录里塞新技能，右侧详情仍保留作者原文和适用场景。

每次打开面板、点 **刷新** 或置顶时都会重新读取这份 JSON，以后改文案不用改代码或重启。文件缺失或格式有误时会自动回退到作者原文，置顶和使用次数不受影响。

遇到还没收录的新技能时，界面会显示作者原文并标出“中文短说明待补充”，有需要再去 JSON 里补一条即可（运行时不会调模型自动翻译）。

浏览和置顶不读取技能正文，不向对话添加上下文。目录、搜索和显示开关不持久化；置顶和累计次数保存在 Host 的 `cheat_sheet` 存储域中，按技能名称跨会话、跨浏览器共享。当前会话不可用的技能不会因置顶而出现。

## 使用次数的含义

次数包含本版本启用后观察到的两类真实加载：用户原生 `/技能名` 成功加载，以及 Agent 的原生 `skill` 工具成功调用，含 codemode 内的调用。只记录名称和累计次数，不保存技能正文或会话消息。

不扫描旧会话，不回填历史；禁用插件期间不计数。写入命令、搜索、刷新、失败调用和在普通文本中提到技能都不会增加次数。同名的不同技能定义共用置顶和次数。

每次打开和点击 **刷新** 时读取最新次数，没有后台轮询。这是启用统计后的累计加载次数，不代表全部历史调用或独立任务数。

## Agent 工具

`cheat_sheet` 工具与界面共用同一套操作：

- `{"action":"state"}`：读取置顶和次数。
- `{"action":"pin","name":"dsh-doc","pinned":true}`：置顶；`false` 为取消置顶。

工具不能修改次数，也不会运行技能。预设限制工具时，需要先允许 `cheat_sheet`。

## 边界

- 需要 Web 输入框、原生 `remote.skills` 接口，以及 Host 的 `storageDomain`、`webServer`、`connection` 和 `tools` 服务；没有会话时不显示入口。
- 更新已加载的 Host 模块可能需要重启 DSH。只刷新浏览器不能保证计数后端生效。
- 弹窗打开期间，外部技能变更在刷新或重新打开后显示。
- 与 Host 命令同名的技能仍遵循原生的命令优先规则。
- 不改变原生 `/` 菜单、技能权限或调用方式。
- 方向键选择技能，在搜索框按 Enter 写入所选命令。搜索框有内容时，Esc 先清空搜索，再按一次关闭。
- 写入使用当前会话的原生 `inputActions`，通过版本守卫向草稿开头插入，不覆盖整份草稿。输入框正在提交或内容版本已变化时，保留弹窗并提示重试。
