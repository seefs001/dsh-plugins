<PluginFacts slug="cheat-sheet" />

当你装了几十个技能记不住名字时，点输入框左侧的 **技能速查** 按钮，即可搜索名称与说明、把常用技能置顶、按实际触发次数降序查看，并一键把 `/skill-name ` 插入光标处。

## 安装

<InstallCommand slug="cheat-sheet" />

需要 `@deepseek-ai/dsh-storage-domain`（默认 profile 已包含）。

## 使用方法

- **搜索与筛选**：打开面板即可看到当前会话原生技能目录中的技能，支持关键词搜索和筛选「仅手动触发」的技能。如果本机存在 `~/.agents/skills/short-descriptions.zh.json`，面板会一并展示中文简述。
- **置顶与真实计数**：点击置顶图标把常用技能固定在顶部；其余技能按实际使用次数降序排列。Host 只统计真正生效的 `/skill` 显式调用与成功执行的 `skill` 工具调用（包括 `codemode` 嵌套调用），不会回溯扫描旧会话，也不会把浏览目录或复制计为使用。
- **插入输入框**：点击或回车某项技能，只在光标位置写入 `/skill-name `，不会直接发送，也不占原本的斜杠菜单。
- **Agent 工具**：插件同时注册 `cheat_sheet` 工具，允许读取置顶与使用计数，或按名称置顶/取消置顶技能（计数本身不可编辑）。

## 数据位置

置顶列表和技能使用计数保存在 Host 的 `cheat_sheet` storage domain，由同一 Host 上的所有会话与浏览器共享。
