<PluginFacts slug="cheat-sheet" />

技能装多了记不住名字时，点击输入框左侧的**技能速查**按钮，即可搜索名称与说明、置顶常用项、按实际加载次数排序，并一键将 `/skill-name ` 写入输入框开头。

## 安装

<InstallCommand slug="cheat-sheet" />

依赖 `@deepseek-ai/dsh-storage-domain`（默认 profile 已包含）。

## 使用方法

- **搜索与筛选**：列出当前会话的技能目录，默认聚焦仅手动触发的技能，可按需开启「包含 Agent 可自动调用的技能」。本机存在 `~/.agents/skills/short-descriptions.zh.json` 时，会优先展示其中的中文简述。
- **置顶与真实计数**：点击置顶图标将常用技能固定在顶部，其余技能按实际使用次数降序排列。Host 实时统计生效的 `/skill` 调用与成功的 `skill` 工具调用（含 `codemode` 嵌套调用）。
- **写入输入框**：点击或按 `Enter` 会把 `/skill-name ` 插到输入框开头，保留你已写的内容，不会直接发送。
- **Agent 工具**：注册 `cheat_sheet` 工具，支持读取置顶与使用计数（`state`）以及切换置顶（`pin`）。

## 数据存储

置顶列表和技能使用计数保存在 Host 的 `cheat_sheet` storage domain，由同一 Host 上的所有会话共享。
