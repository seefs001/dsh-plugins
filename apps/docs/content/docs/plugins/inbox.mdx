后台跑了六个子任务，它们陆续做完、主会话还在汇总时，收件箱角标依然是 0；等主会话停下来问你方案时，角标才变成 1。点开对应条目就能跳回那个会话的原生卡片处理，查看收件箱本身不会替你确认任何请求。

## 每个根会话只占一行

- **需要你**：待回答的问题、计划审阅和仍有效的审批。子任务的请求也会归到根会话下，点开后会直接跳转到真正卡住的子会话。
- **可回看**：显示根会话最近一轮的结束原因和时间（包括出错、受阻或中断，轮次结束不代表整个任务已完成），看完可以只把这次更新标为已读。
- **进行中**：默认折叠，展示还在跑或已排队的父子会话，不会弹通知也不会增加角标。

同一个根会话如果同时有多种状态，只放进优先级最高的分区。普通分叉会话算独立任务，不会继承原会话的未读结果。

## 关掉页面之后

重新连上 Host 时，插件会从原生会话摘要读取结果；如果老会话还没有摘要，打开页面时会先顺序补读最多 8 条，想继续往前翻可以点 **再读一批**。可续答的问题会核对是否已有待发送回复，审批也只认当前仍有效的原生请求。读不到的摘要会直接留出缺口提示，不会悄悄算作已读。

第一次用时，之前的历史结果会出现在 **可回看** 里，但不会亮角标。只打开收件箱不会清空未读，只有当对应对话加载到前台历史里，或者你手动点了 **标为已读**，那一条才会消掉。首次积累比较多时，也可以直接把当前页面显示的一批标为已读，未显示的结果和待处理请求都不受影响。已读记录只保存在当前浏览器的同源存储里，不会跨设备同步。

这个插件只做汇总和跳转，不发声音或系统弹窗，也不接管工具调用、权限审批或模型请求（按目录开启的 AI 摘要除外，默认关闭）。

本地包位于仓库的 `packages/inbox`，适配 DSH 0.2.2-rc.3。试装命令和所需原生 Web 组件见包 README。
