六个 worker 都做完了，父会话继续整理结果，收件箱角标仍是零。父会话需要你选方案时，角标才变成一。点击那一行回到原会话，在原生卡片上回答。打开收件箱不会代你确认请求。

## 一个会话一行

- **需要你**：待答问题、计划审阅和仍有效的审批。子任务的请求归到根会话，点开则进入真正需要处理的子会话。
- **可回看**：显示根会话最近一轮的结束原因和时间，包括出错、受阻和中断，不把轮次结束当作整个任务成功。可以只把这次更新标为已读。
- **进行中**：默认折叠。父会话、运行中的子任务和已排队的下一轮都在这里。取消、已归档任务和单个 worker 的完成不会加角标。

同一根会话同时有多种状态时，只显示在优先级最高的区。普通分叉是独立任务，不会继承父会话的未读结果。

## 关掉页面之后

重新连接 Host 时，插件从原生会话摘要读取结果。老会话缺摘要时，打开页面先顺序补读最多八个，剩余的可以点 **补读下一批**。可继续回答的问题会与待发送回复核对；审批只认仍有效的原生请求，不从历史日志复原。读不到的摘要会显示缺口，不会被当作已读。

首次使用时，已有结果可能出现在 **可回看**，不影响角标。打开收件箱不清空未读；结果在前台主对话的历史中载入，或你点了 **标为已读**，才确认那一次更新。首次回看结果较多时，可以只把当前已显示的一批标为已读。未显示的结果、后来到达的新结果和待处理请求都不受影响。已读记录只在同源浏览器的标签页间共享，不跨设备。浏览器禁止存储时只在本次访问内有效。

插件不新增声音、弹窗或系统通知，也不关闭 DSH 原有通知。它不发送工具结果、不代答、不改权限，不调用模型。

## 本地试用

本地包位于仓库的 `packages/inbox`，适配 DSH 0.2.2-rc.3。试装命令和所需原生 Web 组件见包 README。
