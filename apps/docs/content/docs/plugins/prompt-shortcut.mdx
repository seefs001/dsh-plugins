在输入框左侧工具栏点 **常用片段**。同时启用 **技能速查** 时，它就在技能速查右边；手机窄屏显示为书签图标。比如写到「帮我看一下这次改动」，可以再插入自己存过的「只指出本次改动引入的问题」。无需切换会话，也不会替你发送。

## 保存和使用

1. 第一次打开，有草稿时点 **把这段话存下来**；没有草稿时可以从空白开始，或先试用示例。不想保留它，点示例右侧的 **移除示例**；本次面板内可撤销，否则当前浏览器会记住选择。保存前可以删改正文和名称，不影响原草稿。
2. 按名称或正文搜索，点击结果即可插入。当前行用灰底标出，默认是第一个结果。用 ↑ ↓ 或指针选择，按 Enter 插入高亮项。已有选区时会提示 **替换选中文字**。在输入框撤销一次即可还原本次插入。
3. 点片段旁的 **⋯** 可以置顶、编辑或删除。置顶顺序不随使用频次变化。面板内可撤销上一次删除，关闭面板或再删一条后不再保留上一次的撤销入口。

桌面列表与输入框等宽，浮在输入框上方，不推挤聊天内容；上方空间不足且下方更宽裕时向下展开。右上角显示片段数量，点折叠箭头即可收起。窄屏使用底部面板。如果打开面板后草稿发生变化，插件会拒绝插入。关闭面板，重新放置光标后再试。

## 数据保存在何处

片段只保存在当前浏览器的站点数据里，同一站点的会话共享，不同步到其他浏览器或设备。清除站点数据也会清除片段。保存草稿时只复制确认过的文字，引用按剪贴板文本处理，附件不复制。插件不调用模型，也不向 Agent 提供读取片段库的工具。
