<PluginFacts slug="prompt-shortcut" />

在输入框左侧工具栏添加书签按钮（并支持 `/snippets` 快捷命令），把常用提示词和话术保存在本机 DSH Host 上跨浏览器同步，需要时搜索后直接插入光标处（或替换选中文字），不自动发送。

<InstallCommand slug="prompt-shortcut" />

## 用法

- **搜索与插入**：点击输入框左侧书签按钮或输入 `/snippets`，用方向键或鼠标选中片段后回车或点击，即插入光标处或替换选中文字；支持编辑器一次撤销。
- **新建与保存**：支持新建片段（名称留空时取正文首句）或 **从当前草稿保存**，最多保存 200 条纯文本片段。
- **管理与排序**：支持置顶、编辑和删除（带撤销提示），列表按置顶、最近使用、我的片段顺序分组。
- **导入与导出**：支持导出或导入 JSON 片段文件（按 ID 合并去重）。

## 数据存储

片段以纯文本保存在 Host 的 `prompt_shortcut` storage domain（跨浏览器同步，不包含附件）。首次连接 Host 时会自动从旧版浏览器 `localStorage` 迁移历史片段；当 Host 存储域不可用时自动回退到当前浏览器 `localStorage`（`dsh-prompt-shortcut:library:v1`）。
