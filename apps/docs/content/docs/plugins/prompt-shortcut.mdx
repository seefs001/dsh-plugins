<PluginFacts slug="prompt-shortcut" />

在输入框左侧工具栏放一个书签按钮，把平时经常敲的提示词或话术保存在当前浏览器中。需要时搜一下插入光标位置（或替换当前选中的文字），不会自动发送，留给你改完再发。

## 使用方法

- **打开与插入**：点击输入框左侧书签按钮（若同时启用了 [技能速查](/docs/plugins/cheat-sheet)，位于其右侧），用方向键或鼠标选中片段后回车或点击，即插入当前光标处或替换选中文字。支持编辑器 `Cmd+Z` / `Ctrl+Z` 一次撤销。
- **新建与从草稿保存**：点击 **新建** 填写名称（留空则自动取正文首句）和正文，或直接点击 **从当前草稿保存**。
- **管理与排序**：支持置顶、编辑、删除（带撤销提示）；列表按「置顶 → 最近使用 → 我的片段」顺序分组。初次打开附带一条「示例 · 点一下试试」，可随时移除。

## 数据与边界

- 片段仅以纯文本形式保存在当前浏览器的 `localStorage`（`dsh-prompt-shortcut:library:v1`），不包含图片或文件附件，不上传到 Host，也不跨浏览器同步。
- 不会自动提交发送，也不会改动斜杠命令菜单。
