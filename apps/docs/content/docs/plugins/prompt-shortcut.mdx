<PluginFacts slug="prompt-shortcut" />

在输入框左侧工具栏添加书签按钮，把常用提示词和话术保存在当前浏览器中，需要时搜索后直接插入光标处（或替换选中文字），不自动发送。

## 安装

<InstallCommand slug="prompt-shortcut" />

## 用法

- **搜索与插入**：点击输入框左侧书签按钮，用方向键或鼠标选中片段后回车或点击，即插入光标处或替换选中文字；支持编辑器一次撤销。
- **新建与保存**：支持新建片段（名称留空时取正文首句）或 **从当前草稿保存**。
- **管理与排序**：支持置顶、编辑和删除（带撤销提示），列表按「置顶 → 最近使用 → 我的片段」分组。

片段仅以纯文本保存在当前浏览器 `localStorage`（`dsh-prompt-shortcut:library:v1`），不包含附件，不上传到 Host。
