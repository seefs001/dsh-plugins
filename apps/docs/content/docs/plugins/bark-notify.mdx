当 DSH 智能体暂停等待你处理时，异步向手机发送一条 [Bark](https://bark.day.app/) 推送。

## 安装

<InstallCommand slug="bark-notify" />

## 触发范围

- `user-questions/request`：`ask_user_question`、`exit_plan_mode` 计划审阅及界面授权卡片。
- `approval/request`：工具权限审批。

> `dsh-acp-workbench` 中的外部 ACP CLI 使用独立交互通道，不触发本插件。

## 配置

在 **Plugins** 页面打开 **dsh-bark-notify**：

1. 在 **从 Bark URL 快速填入** 粘贴完整链接（如 `https://your-bark-host/YOUR_KEY/{{title}}/{{content}}?sound=alarm`）点击 **解析填入**，或手动填写服务器地址与 Device Key（无 Web 界面时可通过 `DSH_BARK_KEY` 凭据或环境变量提供）。
2. 保存后点击 **发送测试通知** 确认送达。
3. 按需调整请求方式（`GET` / `POST` JSON）、触发场景开关、延迟推送（`0` 到 `600000` 毫秒，超时前已在界面处理则自动取消）、铃声与分组、正文摘要开关及点击跳转链接。

普通配置写入 profile 的 `cordis.patch.yml`；Device Key 仅存于本机 Host 凭据 `bark-notify/device`。
