<PluginFacts slug="quote-jump" />

把用户消息中的文本引用渲染为可点击的引用块。点击它（或用键盘聚焦后按回车/空格）即可自动展开折叠区、滚动定位到原文所在段落，并用 2.4 秒高亮标出。

## 工作方式与边界

- 替换 `conversation.user.text.node` 中的 `quote` 节点；在单行或摘要场景下仍保留紧凑的内联样式。
- 匹配时忽略空白字符和换行差异，只在当前引用消息**之前**的内容中查找（长引用会自动截取前 48 个非空字符匹配）。
- 仅能定位到当前页面已经加载进来的消息。如果原文属于更早未被拉取的历史记录，提示「原文不在当前已加载的对话里」，向上滚动加载后再点击即可。
