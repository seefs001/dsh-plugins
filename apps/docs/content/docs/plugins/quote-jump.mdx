<PluginFacts slug="quote-jump" />

把用户消息里的引用标签换成引用块。点击它（或聚焦后按 Enter），页面会滚到对话里被引用的原文，并高亮大约两秒。

## 安装

<InstallCommand slug="quote-jump" />

## 原理

只有 Web 部分，Host 入口是空的。

- 在 `conversation.user.text.node` 注册 `quote` 键，priority 50，遮住 `dsh-message-quotes` 自带的渲染器（priority 100）。停用插件即恢复内置标签。
- 匹配时忽略空白，Markdown 排版差异不影响结果。多处匹配时，选引用上方最近的一处。很长的引用只用前 48 个字符匹配。
- 高亮使用 CSS Custom Highlight API，不支持时退回为描边。
- 滚动前会先展开折叠的行（`hidden="until-found"` 和 `<details>`）。

## 限制

- 只能找到页面里已经加载的文字。原消息还在未加载的历史里时，引用块会提示没找到；往上滚动加载后再点一次。
- 引自代码块或表格的文字按文本匹配，渲染后的文字和复制时的选区不一致时可能匹配失败。
