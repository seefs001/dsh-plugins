<PluginFacts slug="quote-jump" />

将用户消息中的文本引用渲染为可点击的引用块，点击（或键盘聚焦后按回车/空格）即可展开折叠区、滚动到原文段落并高亮约 2.4 秒。

## 安装

<InstallCommand slug="quote-jump" />

## 行为说明

- 替换 `conversation.user.text.node` 中的 `quote` 节点，单行或预览场景保留紧凑内联样式。
- 匹配时忽略空白与换行差异，只在当前引用消息之前已加载的内容中查找（长引用截取前 48 个非空字符）。
- 原文尚未加载时会提示「原文不在当前已加载的对话里」，向上滚动加载历史后再点即可。
