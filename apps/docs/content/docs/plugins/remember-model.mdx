<PluginFacts slug="remember-model" />

在顶层会话切换到新的模型或推理强度后，自动更新 DSH 默认模型，并通知已连接的浏览器刷新目录，让新建会话直接沿用上次选择。

## 安装

<InstallCommand slug="remember-model" />

纯 Host 插件，无界面与独立配置项。

## 工作机制

1. 监听顶层会话的 `model/selection` 事件，忽略子代理会话。
2. 写入 DSH 原生的 `agent-default-model` 配置。
3. 400 ms 去抖后广播 `llm/models-updated`，触发浏览器同步刷新默认模型。

停用或卸载后，已写入原生配置的默认模型保持不变。
