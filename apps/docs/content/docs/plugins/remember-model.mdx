<PluginFacts slug="remember-model" />

你在任意顶层会话里选了模型和推理强度后，新会话就从这个选择开始。

## 安装

<InstallCommand slug="remember-model" />

没有设置项，也没有界面。

## 原理

1. 顶层会话记录 `model/selection` 事件时，插件调用 `agentDefaultModel.saveSelection()` 保存这个选择。子代理会话会自己选模型，所以跳过。
2. 浏览器缓存了带默认值的模型目录，只在少数事件后重新加载。插件每次保存后等待 400 ms，发出 `llm/models-updated`，让已连接的浏览器重新加载目录。否则新会话的选择器会继续显示旧的默认值。

保存的默认值就是 DSH 正常的 `agent-default-model` 配置，你仍然可以手动修改。
