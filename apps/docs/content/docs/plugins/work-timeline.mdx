在输入框上方摘要条与右侧详情面板中展示会话级的工作计划、修订历史和关联产物（交付物与依据文件）。

<Callout type="info" title="主入口与工具子入口">
主入口注册会话投影与界面视图；`work_read` 和 `work_update` 由子入口 `dsh-work-timeline/tools` 提供。与 [Pi 工具](/docs/plugins/pi-tools) 同时启用时，`pi` 预设会自动挂载这两个工具；其他预设也可显式引入该子入口。
</Callout>

## 视图

- **输入框摘要条**：显示当前工作标题、完成进度、受阻项与下一步任务，点击打开右侧详情面板。
- **计划**：查看所有步骤状态（待开始 / 进行中 / 受阻 / 已完成 / 已取消）、受阻原因与阶段结果。
- **过程**：按修订号（`revision`）查看每轮调整原因及步骤、产物的增删改记录（最多保留最近 100 次修订，支持标识从来源会话继承的计划）。
- **产物**：按步骤筛选 `deliverable`（交付物）和 `evidence`（依据），点击直接在文件侧栏打开当前磁盘上的文件。

## 数据存储与并发

- 状态随会话日志里 `work_update` 的结果（`meta.dshWorkTimeline`）保存，不使用单独的 storage domain。
- `work_update` 通过 `expectedRevision` 做乐观并发检查，须由模型直接调用（禁止在 `codemode` 脚本中嵌套调用）。
