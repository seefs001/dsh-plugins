所有插件的 GitHub 安装地址都使用下面的结构，把 `<name>` 换成目录名即可：

```text
github:seefs001/dsh-plugins#main&path:/packages/<name>
```

| 插件 | 作用 | 组成 |
| --- | --- | --- |
| [模型引用](./model-reference.mdx) | 输入 `#` 插入带推理强度和快速模式的模型标签 | Host + Web |
| [快速模式](./service-tier.mdx) | 为 Responses 模型切换 `service_tier: "priority"` | Host + Web |
| [记住模型](./remember-model.mdx) | 新会话沿用上次的模型与推理强度 | Host |
| [最近会话](./recent-sessions.mdx) | `@` 菜单中的会话按最近活动排列 | Web |
| [会话分组](./session-groups.mdx) | 自定义分组、排序、组内置顶与 Agent 工具 | Host + Web |
| [压缩状态](./compaction-status.mdx) | 在输入框上方显示上下文压缩状态与已等待时间 | Host + Web |
| [自动审查模型](./auto-review-model.mdx) | 单独设置 Auto review 的模型和提示词 | Host + Web |
| [引用跳转](./quote-jump.mdx) | 点击引用块定位并高亮原文 | Web |
| [工具透镜](./tool-lens.mdx) | 从工具行打开技能、文件、完整输出与子会话 | Web |
| [联网搜索](./web-access.mdx) | `grok_search` 和 `openai_search`，返回带引用的回答 | Host + Web |

## 插件之间的关系

- 模型引用会读取快速模式的状态，让 `#` 标签带上 ⚡。不装快速模式时，模型引用仍然可用。
- 最近会话曾属于模型引用，现在是独立插件。
- 自动审查模型是内置实验性 Auto review 的扩展，不会自行启动审查功能。
- 联网搜索不替换 dsh 内置的 `web_fetch`。
