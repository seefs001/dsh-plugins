所有插件的 GitHub 安装地址都使用下面的结构，把 `<name>` 换成目录名即可：

```text
github:seefs001/dsh-plugins#main&path:/packages/<name>
```

## 插件之间的关系

- 模型引用会读取快速模式的状态，让 `#` 标签带上 ⚡。不装快速模式时，模型引用仍然可用。
- 子代理模型只补充子代理的只读显示，不提供选模入口，也不依赖模型引用、快速模式或记住模型。
- 最近会话曾属于模型引用，现在是独立插件。
- 自动审查模型是内置实验性 Auto review 的扩展，不会自行启动审查功能。
- 联网搜索配置就绪且支持网页搜索时，会隐藏内置 `web_search`；只启用 X 搜索时不会替换。`web_fetch` 不受影响。
- Git 改动依赖已启用的 Change requests & worktrees bundle，不会自行运行 Git。
- AI 小伙伴只读取当前显示对话的活动；角色图需要访问外部站点，素材不属于插件代码的 MIT 授权。
