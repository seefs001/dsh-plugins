所有插件的 GitHub 安装地址结构相同，把 `<name>` 换成目录名：

```text
github:seefs001/dsh-plugins#main&path:/packages/<name>
```

标签依次是运行位置、最低 DSH 版本和额外要求。完整的版本范围见 [版本与边界](/docs/compatibility)。

## 插件之间的关系

- # 引用模型会读取快速模式的状态，让 `#` 标签带上 ⚡。不装快速模式也能用。
- 最近会话优先原来是 # 引用模型的一部分，现在是独立插件。
- 子代理模型、# 引用模型和记住上次模型互不依赖。
- 自动审查模型扩展的是实验性的 Auto review，不会自己开启审查。
- 联网搜索的 `grok_search` 和 `openai_search` 也可以出现在 Pi 工具的选择面板里，前提是两个插件都已安装、搜索已配置好。
- Git 变更和分支切换都依赖 Change requests & worktrees，但彼此独立。
