所有插件都使用相同的 GitHub 安装格式，将 `<name>` 替换为插件目录名即可：

```text
github:seefs001/dsh-plugins#main&path:/packages/<name>
```

每行标签标明了运行位置与前置要求，详见 [依赖与运行](/docs/compatibility)。

## 常用组合

- **# 引用模型 + 角色管理 + 快速模式**：同时启用时，模型与角色在同一个 `#` 菜单中分组展示，模型标签会自动带上并传递 `⚡` 档位状态。
- **Pi 工具 + Pi MCP 服务器 + 联网搜索 / 画图**：`pi` 预设可独立使用；启用官方 `@deepseek-ai/dsh-timeline` 自动透传 `timeline_*` 工具，启用 `dsh-pi-mcp` 自动桥接 Pi 的 MCP 服务器，并透传搜索与画图工具。
- **工具透镜 + 编辑消息 + 引用跳转 + Wait, what?**：分别增强工具调用行、用户消息编辑、引用跳转与回复解释。
