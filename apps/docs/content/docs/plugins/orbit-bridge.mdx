<PluginFacts slug="orbit-bridge" />

只读巡检 [Orbit](https://github.com/coollabsio/orbit) 项目的桥接插件。每次完整读取选定项目的所有任务，与上次已处理的快照对比，记录新增、字段变化和消失的任务。所有结果保存在 Host 本地，绝不向 Orbit 写入任何内容。

<Callout type="info" title="前置要求">
需要在 DSH 连接了 Orbit MCP 服务器，且 profile 包含 `@deepseek-ai/dsh-storage-domain`（默认已包含）。
</Callout>

## 创建与运行巡检

<Steps>
<Step>

### 创建巡检规则

打开左侧栏 **Orbit 执行桥**，点击 **新建规则**，填写名称、Orbit 项目 ID（最多 10 个）和 MCP 服务器名称（默认 `orbit`），先保存为草稿，核对范围后点击 **确认并启用**。

</Step>
<Step>

### 执行检查

支持两种检查入口：

- **人工「立即检查」**：owner 在页面点击 **立即检查**，Host 不起用 Agent，直接通过只读工具管线拉取全量任务并生成程序比对摘要。
- **受限 Agent 巡检**：由仅暴露 `orbit_bridge_observe`、`orbit_bridge_submit_outcome` 和对应 Orbit 只读 MCP 工具的受限会话触发，存在变更时要求 Agent 提交引用 `changeKeys` 的结构化 `facts`（20 分钟超时记为 `no_outcome`）。

</Step>
</Steps>

## 边界与限制

- **严格只读与隔离**：运行期间工具守卫会拒绝调用规定范围以外的任何工具（包括跨项目 ID 越权读取）。每次编辑规则都会退回草稿状态，需人工重新确认。
- **定时任务草稿**：可选填写 `RRULE` 与受限预设生成未审阅的定时任务 JSON 草稿，插件本身**不会**替你创建 DSH 定时任务，需你确认后前往自动化页面配置。
- **存储上限**：数据存于 Host `orbit_bridge` storage domain（最多 20 条规则，每条保留最近 30 次运行及基线依赖运行）。
