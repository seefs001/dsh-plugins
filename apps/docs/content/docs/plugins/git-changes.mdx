<PluginFacts slug="git-changes" />

在输入框下方、活动和用量标签旁边加一个 Git 入口，显示当前分支、增删行数和未提交的文件数。点它会在右侧边栏打开 diff，并直接定位到“未提交”范围。

## 安装

<InstallCommand slug="git-changes" />

先在 Plugins 页启用 **Change requests & worktrees**（`@deepseek-ai/dsh-experimental-forge-bundle`）。插件读取这个面板的数据并打开它的本地改动标签页，没有它时入口不会出现。

## 原理

只有 Web 部分，Host 入口是空的。

- 在 `conversation.composer.dock` 注册 `git-changes` 入口（order 2，排在自带标签之后）。
- 通过当前会话的 `forgePanel.follow` 获知分支和检出变化，再（防抖后）读取 `forgePanel.localDiff({ kind: 'uncommitted' })` 得到数字。统计的是相对 HEAD 的改动，包括未跟踪的文件。
- 点击打开 `dsh-resource://forge-changes/<session>/local`，和面板里本地改动卡片打开的是同一个标签页。
- 包装 forge 改动标签页（`sidebar.right.pane.tab`，priority -10），每个新的本地改动标签页会从 Branch 范围切到 Uncommitted 一次。之后你再选别的范围会保持不变。
- 工作区干净时显示“无改动”，不在 Git 仓库里时隐藏。

## 限制

- 默认范围依赖 forge 标签页的内部 store（`byTab[tab].scope` 和 `scoped` action）。DSH 升级改变它们后，标签页会重新从 Branch 打开，入口本身照常工作。
- diff 超过 forge 面板的 `maxDiffBytes` 时，入口显示“无改动”。
