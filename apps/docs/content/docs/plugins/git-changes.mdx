<PluginFacts slug="git-changes" />

在输入框底部状态栏显示当前 Git 分支、未提交增删行数和变更文件数，点击直接在右侧边栏打开本地变更面板，并将新开标签默认切到 **未提交** 范围。

<Callout type="info" title="依赖 Forge 服务">
需要启用 `Change requests & worktrees`（`@deepseek-ai/dsh-experimental-forge-bundle`）。非 Git 目录或未启用 Forge 时自动隐藏。
</Callout>

## 安装

<InstallCommand slug="git-changes" />

## 工作方式

- 订阅 `forgePanel.follow` 流，在工作区或提交变化时以 400 ms 防抖查询 `uncommitted` 差异统计（含未跟踪文件数）。
- 点击打开右侧 `local` 变更面板，自动将新开标签的默认范围切为 **未提交**。
- 纯 Web 端消费 Forge 数据流，无额外配置。
