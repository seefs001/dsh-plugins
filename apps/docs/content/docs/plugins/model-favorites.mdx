<PluginFacts slug="model-favorites" />

配置多个 provider 后，模型列表往往很长。启用本插件后，可以直接在模型列表中为常用模型点亮星标，收藏的模型会固定在模型列表与 `/model` 弹窗顶部，也会直接出现在输入框模型菜单中一键切换。

## 安装

<InstallCommand slug="model-favorites" />

## 使用方法

<Steps>
<Step>

### 在模型列表中加星收藏

点开输入框底部的模型选择器并进入 **模型** 列表，点击任意模型行左侧的星标即可收藏或取消收藏，不会触发切换模型，也不会关闭当前列表。

</Step>
<Step>

### 顶部置顶与一键切换

- **模型列表顶部**：已收藏且当前可用的模型会自动置顶显示在 **收藏模型** 分组中，并随搜索框输入同步过滤。
- **模型根菜单快捷区**：点开模型选择器后，前 5 个收藏模型会直接展示在根菜单中，点一次即可切换，无需再进入二级列表。
- **`/model` 弹窗**：输入 `/model` 切模型时，收藏的模型同样会置顶在 **收藏模型** 分组中。

</Step>
<Step>

### 管理收藏与调整顺序

在模型根菜单中点击 **收藏模型** 进入管理面板，可以一键收藏或取消收藏当前模型、使用上下箭头调整常用顺序，以及清理已经下线或不可用的旧模型记录。

</Step>
</Steps>

## 存储与同步

- 收藏列表以 `{ provider, model }` 顺序保存在 DSH Host 的 `model_favorites` 存储域（`~/.dsh/storages`），跨浏览器会话共享。
- 同一浏览器打开多个标签页时，通过 `BroadcastChannel` 实时同步，不占用常驻长连接。
- 同时注册 `model_favorites` 工具，支持在对话中按需查询或整理收藏列表。
