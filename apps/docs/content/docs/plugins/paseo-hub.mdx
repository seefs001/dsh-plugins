<PluginFacts slug="paseo-hub" />

将当前 DSH Host 注册为 [Paseo Hub](https://github.com/getpaseo/hub) 的 daemon。接入后，Hub 来自 GitHub、Slack、Discord、Linear、Telegram、Webhook、定时或手动触发的任务会在本机跑成原生 DSH 会话；同时内置组织 API 控制台与 Agent 工具。

<Callout type="info" title="前置要求">
需要支持 daemon 上报 provider 的 Paseo Hub（或已支持 `dsh` 的旧版 Hub），以及 `@deepseek-ai/dsh-permission-presets` 和 `@deepseek-ai/dsh-storage-domain`（默认 profile 已包含）。
</Callout>

## 接入与触发器写法

1. 在左侧栏打开 **Paseo Hub**，填写 Hub origin（如 `https://hub.example.com`），点击**登录**并在浏览器批准授权码；无浏览器时可用含 `daemons:enroll` 权限的组织 API Key 一次性注册。
2. 在 Hub 触发器 YAML 中将 `provider` 设为 `dsh`，建议显式指定对应的 DSH 权限预设作为 `mode`：

```yaml
run:
  target: { daemon: my-mac, cwd: /Users/me/project }
  agent:
    provider: dsh
    model: messages/claude-opus-5-5   # 可选：<DSH provider>/<模型>
    thinkingOptionId: high            # 可选：推理强度
    mode: workspace-write             # 可选：映射 DSH 权限预设
  prompt: 修复失败的测试并开 PR。
```

新版 Hub 的表单会在 daemon 提供权限模式时要求选择；YAML 可以省略 `mode`，此时插件使用映射后的默认权限预设。无人值守任务建议显式指定。

要在 Hub 的工作目录下拉框中显示项目，在该插件的 Host 配置中设置 `sharedProjectPaths`，例如 `sharedProjectPaths: ["/Users/me/project"]`。默认不公开任何目录，仍可手填绝对路径。这只是目录建议，不限制运行可使用的路径；开启 `listWorkspaces` 也不会把侧栏目录分享给 Hub。

## 工作台标签页

| 标签页 | 功能 |
| --- | --- |
| **概览** | 运行统计（点击可按状态跳转）、daemon 连接状态、重连/断开，以及最近 5 条运行与活动 |
| **运行** | 本机承载的全部 Hub 运行（搜索、状态筛选、分页），展开可查看预设/模型/worktree/报错，支持停止、归档与恢复 |
| **活动** | 记录连接、运行与组织 API 操作日志（保留最近 1000 条） |
| **Hub API** | 独立保存组织 API Key，支持触发器搜索、YAML 校验与安装、带 `deliveryKey` 的手动触发以及旧版配置 bundle |
| **设置** | 查看映射到 Hub 的 mode 列表、可复制的触发器模板与当前插件配置 |

## Agent 工具与边界

- **工具**：`paseo_hub` 负责只读查询与校验（`status`、`check`、`projects`、`triggers`、`get-trigger`、`resources`、`setup-resources`、`validate-trigger`、`validate-configuration`）；`paseo_hub_write` 负责写入（`install-trigger`、`install-configuration`、`dispatch`），默认关闭，需在 **Hub API** 页显式开启。
- **会话隔离**：Hub 的 `reply`、`finish_execution` MCP 工具及环境变量（`PASEO_*`、`GH_TOKEN`）仅挂载到 Hub 触发的会话，不影响日常会话；所用预设需支持会话级 MCP 工具（如 `standard` 或 `pi`）。
- **worktree 与凭据**：worktree 支持 `branch-off` 模式（需启用 worktree 服务）；一台 Host 同一时间接入一个 Hub。daemon 与组织 API 密钥分别保存在 DSH credentials 的 `paseo-hub/daemon` 与 `paseo-hub/api`，请求锁定已保存 origin。
