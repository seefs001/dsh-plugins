为聊天流中的常见工具调用行增加直达右侧栏的快捷按钮，不用先展开原始参数或在文件树中翻找。

## 安装

<InstallCommand slug="tool-lens" />

## 支持的工具行

| 工具 | 增强效果 |
| --- | --- |
| `skill` | 点击技能名在右侧文件侧栏打开 `SKILL.md`，点击行展开技能正文 |
| `edit` / `write` / `apply_patch` | 启用 Forge 时，行尾显示 **查看变更**（多文件补丁显示变更文件列表），点击在右侧 Git 变更面板展开定位该文件 |
| `grep` / `glob` | 行尾显示命中文件或文件列表，点击打开并定位到首个命中行 |
| `web_search` / `web_fetch` | 行尾显示网页来源链接，默认在右侧 Browser 面板打开（`Cmd`/`Ctrl` 点击在新标签页打开） |
| `subagent` / `send_message` / `interrupt_agent` | 点击在右侧面板打开对应子代理会话（不含 `external` 外部子代理） |
| `bash`、`job_output`、`terminal_read`、`workflow`、`lsp`、`cordis_inspect`、`session_*` | 输出写入 spill 文件时，行尾显示 **完整输出** 按钮，点击在右侧预览完整内容 |

纯前端视图增强，不修改会话记录也不重跑工具，停用即恢复内置视图。
