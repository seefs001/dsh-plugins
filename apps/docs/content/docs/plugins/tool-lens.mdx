为聊天流里的常见工具调用行增加直达右侧边栏的快捷按钮，不用先展开整段原始参数或手动去文件树里翻找。

## 支持的工具行快捷操作

| 工具 | 增强效果 |
| --- | --- |
| `skill` | 替换内置行，点击技能名直接在右侧文件侧栏打开对应的 `SKILL.md`（点击空白处展开参数与说明） |
| `grep` / `glob` | 行尾显示命中文件或文件数量按钮，点击直接打开对应文件并定位到首个命中行号 |
| `web_search` / `web_fetch` | 行尾显示网页来源链接，默认在右侧 Browser 面板打开（按住 `Cmd`/`Ctrl` 在浏览器新标签打开） |
| `subagent` / `send_message` / `interrupt_agent` | 一键在右侧面板打开或聚焦对应子代理会话 |
| `bash`、`job_output`、`terminal_read`、`workflow`、`lsp`、`cordis_inspect_*`、`session_*` | 输出被写入 spill 文件时，行尾浮动 **完整输出** 按钮，点击直接在右侧预览完整日志 |

## 边界说明

- 在 `tool.call.toolview` 槽位包装或替换默认视图，停用后立即还原原生行样式。
- 仅读取已有工具结果与会话元数据，不会重新执行工具。对于外部模式（`external`）子代理不提供原生子代理面板打开按钮。
