<PluginFacts slug="session-groups" />

当侧栏会话越来越多时，用 **会话分组** 按项目或主题归类。分组作为折叠文件夹显示在工作区列表上方，分组状态保存在 Host 上，多窗口、多浏览器和 Agent 之间通过 SSE 实时同步。

## 安装

<InstallCommand slug="session-groups" />

需要 `@deepseek-ai/dsh-storage-domain`（默认 profile 已包含）。

## 使用方法

- **侧栏文件夹与拖拽**：分组固定出现在工作区列表上方，支持直接把会话拖入已有分组，或拖到新建区域直接创建分组。已加入分组的会话会从默认未分组区域归类移出，保持列表整洁。
- **右键菜单操作**：在任意会话的右键菜单中可 **加入分组**、**移到分组**、**在组内置顶 / 取消置顶** 或 **从分组移除**。组内置顶会话固定排在分组最前，其余按最近活动排列。
- **分组管理页**：点击左侧栏 **会话分组** 图标，可集中新建、重命名、上移/下移分组顺序、搜索添加会话，或删除分组。
- **Agent 工具**：插件同时注册 `session_groups` 工具（`list`、`create`、`rename`、`delete`、`move_group`、`add`、`remove`、`pin`），让 Agent 也能按你的指令整理会话。

## 数据与规则

- 分组数据保存在 Host 的 `session_groups` storage domain。
- 一个会话同一时间只属于一个分组；加入新分组时会自动从原分组移出。
- 最多支持创建 **200** 个分组。删除分组只解散分组本身，**不会删除任何会话**。
