<PluginFacts slug="session-groups" />

按项目或主题整理侧栏会话。分组作为折叠文件夹显示在工作区列表上方，状态保存在 Host 上，通过 SSE 实时同步到所有打开的客户端和 Agent。

## 安装

<InstallCommand slug="session-groups" />

需要 `@deepseek-ai/dsh-storage-domain`（默认 profile 已包含）。

## 使用方法

- **侧栏文件夹与拖拽**：分组显示在工作区列表上方，支持拖入已有分组、拖到新建区建组，或拖回原列表移出分组。
- **右键菜单**：在会话上右键可 **加入分组**、**移到分组**、**组内置顶 / 取消置顶** 或 **移出分组**。置顶会话固定排在组内顶部，其余按最近活动排列。
- **分组管理页**：点击侧栏 **会话分组** 图标，集中新建、重命名、排序、搜索添加会话或删除分组。
- **Agent 工具**：注册 `session_groups` 工具（`list`、`create`、`rename`、`delete`、`move_group`、`add`、`remove`、`pin`）。

## 数据与规则

- 数据保存在 Host 的 `session_groups` storage domain。
- 每个会话最多属于一个分组，加入新分组时自动从原分组移出。
- 最多支持 **200** 个分组；删除分组只解散分组，保留其中的会话。
