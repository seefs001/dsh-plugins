<PluginFacts slug="session-groups" />

在侧边栏会话列表顶部以文件夹形式显示自定义分组，原有的工作区列表排在下面。每个分组有自己的置顶会话，置顶的会话排在组内最前面。分组保存在 Host 上，所有连到同一个 DSH 的浏览器和 Agent 看到的是同一份。

## 安装

<InstallCommand slug="session-groups" />

需要 `@deepseek-ai/dsh-storage-domain`，默认 profile 已包含。

## 侧边栏文件夹

- 分组显示在侧边栏会话列表顶部，像工作区文件夹一样。下面是内置的工作区列表，只保留不属于任何分组的会话；已分组的会话只出现在它的文件夹里。
- 点击文件夹展开或收起，状态保存在当前浏览器。悬停文件夹可以重命名或删除；双击或按 F2 也能重命名。把一个文件夹拖到另一个文件夹上可以调整顺序。
- 文件夹行显示会话数。会话行在运行时显示圆点，并显示最后活动时间；组内置顶的会话显示置顶标记。悬停会话行可以组内置顶或移出分组，右键打开内置的会话菜单，其中也有分组操作。
- 把工作区列表里的会话拖到文件夹上即可加入；把文件夹里的会话拖回工作区列表即可移出分组。拖动会话时文件夹下方会出现 **拖到这里新建分组**，松手即新建分组并进入重命名。
- 侧边栏搜索有输入时文件夹隐藏，搜索结果包含所有会话。

被隐藏的行仍计入工作区默认显示的前五行，所以含已分组会话的工作区在 **显示更多** 之前可能显示得少一些。

## 分组页

- 点侧边栏面板列表里的 **会话分组** 打开分组页。
- **新建分组** 新建一个分组。双击名称或点铅笔图标重命名。
- 悬停在分组标题上，可以添加会话、重命名、调整顺序或删除分组。删除分组不会删除其中的会话。
- 悬停在会话行上，可以在组内置顶或移出分组。置顶的会话排在前面，最近置顶的最先；其余按最后活动时间排序。
- 在侧边栏右键会话，可以选择 **加入分组** / **移到分组**、**组内置顶** 和 **移出分组**。

把会话从原生侧边栏或分组页拖到某个分组上，就会加入或移到该分组；折叠的分组会自动展开。拖动时分组页底部会出现 **拖到这里新建分组**，松手即新建一个包含该会话的分组，并直接进入重命名。未知或空白的会话会被忽略，拖回当前分组不做任何事。拖动只改变成员，不改变组顺序或置顶顺序。

一个会话最多属于一个分组，加入另一个分组就会移过去。内置的置顶不受影响。

## 数据

分组保存在 Host 的 `session_groups` storage domain。使用默认 `json` 后端时，文件是 `~/.dsh/storages/session_groups.json`。Host 通过 server-sent events 把改动推给打开的页面。

## Agent 工具

Host 注册 `session_groups` 工具，操作与界面相同：`list`、`create`、`rename`、`delete`、`move_group`、`add`、`remove`、`pin`。每次调用都返回完整的分组结果。

## HTTP

| 路由 | 方法 | 用途 |
| --- | --- | --- |
| `/session-groups/state` | GET | 当前分组 |
| `/session-groups/op` | POST | 执行一个操作，参数与工具相同 |
| `/session-groups/events` | GET | 每次改动后推送完整状态的 SSE |

所有路由都走 Host 的常规连接检查。
