<PluginFacts slug="branch-switcher" />

在新会话发送首条消息前，点击分支标签直接切换当前目录的本地 Git 分支；勾选 **新建工作树** 时继续走 DSH 原生工作树创建流程。

<Callout type="info" title="依赖 Forge 服务">
需要启用 `Change requests & worktrees`（`@deepseek-ai/dsh-experimental-forge-bundle`）。
</Callout>

## 安装

<InstallCommand slug="branch-switcher" />

## 用法

- **页面切换**：在未开始对话的新会话页顶部，点击分支标签展开本地分支列表（按最近提交时间排序，支持搜索），选中即可切换。
- **命令与工具**：注册 `/branch-switcher` 命令与 `branch_switcher` 工具（`list` / `switch`），与页面共用同一套沙箱 Git 逻辑。

<Callout type="warn" title="切换影响共享同一目录的所有会话">
该操作直接切换当前工作目录的分支。仅切换已有本地分支；遇到未提交改动冲突、只读权限模式或已发送首条消息时会拒绝切换。
</Callout>
