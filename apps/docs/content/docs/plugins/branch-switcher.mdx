<PluginFacts slug="branch-switcher" />

在「新会话」页面发第一条消息之前，点击分支标签就能直接切换当前目录的本地分支，不用专门开终端敲 `git switch`；如果勾选 **新建工作树**，仍沿用 DSH 原生的工作树创建流程。

<Callout type="info" title="依赖 Forge 服务">
需要启用 `Change requests & worktrees`（`@deepseek-ai/dsh-experimental-forge-bundle`）。
</Callout>

## 安装

<InstallCommand slug="branch-switcher" />

## 用法

- **页面按钮**：在尚未开始对话的新会话页顶部，点击分支胶囊展开本地分支列表（按最近提交时间排序，支持搜索），选定分支即可切换。
- **命令与工具**：同时注册 `/branch-switcher` 用户命令与 `branch_switcher` 工具（`list` / `switch`），在底层共用同一套沙箱 Git 逻辑。

## 边界说明

<Callout type="warn" title="切换的是当前工作目录的真实分支">
所有指向同一工作目录的会话和终端都会立即看到新分支。插件只切换本地已有分支，不执行 `fetch`、不建新分支、不 `stash`、不强制覆盖；遇到冲突或处于只读权限模式时会明确拒绝。第一条消息发出后不可再通过此入口切换。
</Callout>
