<PluginFacts slug="service-tier" />

当当前模型走 OpenAI Responses 协议时，输入框右侧模型选择器旁会出现 `⚡` 按钮，按 `provider/model` 切换服务档位。

## 安装

<InstallCommand slug="service-tier" />

## 显示条件与档位

仅在 provider 显式配置 `api: openai-responses` 或属于 pi-ai 内置目录中默认走 Responses 协议的路由时显示 `⚡` 按钮：

| 模型范围 | 图标状态 | 可选档位 |
| --- | --- | --- |
| 支持 Ultrafast 的模型（`gpt-6.2-sol`、`gpt-6.2-astra`、`gpt-6.1-sol`、`gpt-6-astra`） | 空心 / 单实心 / 双实心闪电 | **默认速度**、**快速**（`priority`）、**超快**（`ultrafast`） |
| 其他 Responses 模型 | 空心 / 单实心闪电 | 点击切换 **默认速度** 与 **快速**（`priority`） |

<Callout type="warn" title="档位与计费">
`priority` 和 `ultrafast` 会通过请求体的 `service_tier` 字段传给上游服务，可能产生对应档位费用；切回 **默认速度** 会移除覆盖项。
</Callout>

## 配置与联动

档位实时写入 profile 的 `cordis.patch.yml`（`tiers` 字段），并在发送 Responses 请求时通过 pi-ai 的 `onPayload` 注入 `service_tier`：

```yaml
- id: service-tier
  config:
    tiers:
      responses/gpt-6.1-sol: priority
```

同时安装 [# 引用模型](/docs/plugins/model-reference) 时，`#` 标签会同步显示并携带对应的 `⚡` 状态。
