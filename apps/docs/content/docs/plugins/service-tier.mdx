<PluginFacts slug="service-tier" />

在模型选择器旁加一个 ⚡ 开关。对某个模型打开后，该模型的请求会带上 `service_tier: "priority"`。

只有当前模型的 provider 使用 OpenAI Responses API（`llm-pi-ai` 里的 `api: openai-responses`）时才显示这个开关，因为只有这条路由接受该字段。

## 安装

<InstallCommand slug="service-tier" />

## 使用

点 ⚡ 切换当前模型的快速模式。切换立即生效，随后通过 config editor 保存到 profile。

<Callout type="warn">
OpenAI 和兼容网关对 priority 处理单独计费。长期开启前先确认 provider 的价格。
</Callout>

## 配置

```yaml
- id: service-tier
  config:
    tiers:
      responses/gpt-6.1-sol: priority
```

`tiers` 由 ⚡ 按钮维护。

## 原理

| 部分 | 作用 |
| --- | --- |
| Host（`lib/index.js`） | 挂在 `llm-pi-ai/model-defaults` waterfall 上，为开启的 Responses 路由 `provider/model` 加上 `serviceTier: 'priority'`。提供 `GET /service-tier/state` 和 `POST /service-tier/set` |
| Web（`lib/client.js`） | 在 `conversation.input.right` 渲染 ⚡ 按钮，乐观更新开关状态 |

两个路由都使用 Web API 的常规认证。`POST /service-tier/set` 接受 `{ "provider": string, "model": string, "fast": boolean }`，请求体上限 16 KiB。

[# 引用模型](/docs/plugins/model-reference) 读取这里的状态，给 `#` 标签加上 ⚡。
