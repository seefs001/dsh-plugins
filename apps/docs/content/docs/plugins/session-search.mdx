<PluginFacts slug="session-search" />

点击侧栏「新建会话」下方的 **搜索会话** 打开居中搜索面板（侧栏收起时显示为放大镜图标）。

## 安装

<InstallCommand slug="session-search" />

## 用法

- 未输入关键词时，按最近活动时间列出未归档的主会话（不含空白会话与子代理，最多显示 20 条）。
- 输入标题、工作区、会话 ID 或对话内容，先展示标题和工作区匹配结果，随后补上 DSH 正文搜索命中的文本片段。
- 支持 `↑` / `↓` 切换、`Enter` 打开、`Esc` 或点击遮罩关闭。
