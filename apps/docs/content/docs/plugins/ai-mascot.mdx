## 行为与特性

- **按模型 ID 匹配**：当前会话的模型 ID 匹配 `claude` 时显示 Claude，匹配 `gpt`、`chatgpt`、`codex` 或 `o1`/`o3`/`o4` 时显示 GPT；其他模型或全局管理面板自动隐藏。
- **只看当前会话**：仅响应画面正在展示的对话（并发工具时显示最近发起的调用，包括子调用），忽略后台其他会话；正常回复结束会庆祝 2.4 秒，手动停止或报错不庆祝。
- **交互与偏好**：支持拖拽移动、键盘方向键微调（配合 `Shift` 大步移动）、收起为 40px 圆按钮、切换「小 / 标准」尺寸与关闭动作动画，并遵守系统 `prefers-reduced-motion`。位置和偏好保存在浏览器 `localStorage`（`dsh-ai-mascot:preferences`）。
- **外部请求**：首次显示时浏览器直接从 `selinlee.github.io` 加载角色参考图（无对话内容、无 referrer），并在浏览器内存中自动去除外围白底，不打包也不上传图片。
