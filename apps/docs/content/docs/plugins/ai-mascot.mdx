## 行为与交互

- **按模型 ID 显示**：模型 ID 匹配 `claude` 时显示 Claude，匹配 `gpt`、`chatgpt`、`codex` 或 `o1`/`o3`/`o4` 时显示 GPT，其他模型或管理面板自动隐藏。
- **跟随当前会话**：仅响应画面当前展示的对话，正常完成回复后庆祝 2.4 秒。
- **位置与偏好**：支持拖拽或键盘方向键调整位置（配合 `Shift` 大步移动）、收起为 40px 按钮、切换「小 / 标准」尺寸和关闭动画，并遵守 `prefers-reduced-motion`。偏好保存在浏览器 `localStorage`（`dsh-ai-mascot:preferences`）。
- **外部图片**：首次显示时从 `selinlee.github.io` 加载角色参考图（无对话内容、无 referrer），并在浏览器内存中去除外围白底。
