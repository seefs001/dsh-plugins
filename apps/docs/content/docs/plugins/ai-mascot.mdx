在 Web 界面右下角显示 GPT 或 Claude 的 Q 版角色。它只跟随当前显示的对话，切换动作、提示和小道具，不会被后台其他会话的活动带跑。

## 安装

<InstallCommand slug="ai-mascot" />

安装后刷新页面，打开使用受支持模型的对话。

## 哪些模型会显示

插件按模型 ID 识别角色，不按 provider 名称：GPT、ChatGPT、Codex 和 OpenAI o1/o3/o4 的模型 ID 显示 GPT 角色，Claude 的模型 ID 显示 Claude 角色，其他模型不显示。所以 OpenAI 兼容 provider 下的其他模型不会被当作 GPT。切到全局面板或离开对话时角色隐藏。

## 动作

| 当前活动 | 表现 |
| --- | --- |
| 空闲 | 安静呼吸，没有气泡和徽章 |
| 思考 | 微微歪头，思考点渐隐渐现 |
| 读文件、图片、技能、网页 | 慢慢点头，手里一本打开的书 |
| 搜索、grep、glob | 左右张望，带扫描徽章 |
| 写入、编辑 | 小幅打字动作，带代码道具 |
| 回复 | 拿着纸条和移动的铅笔，与写代码区分开 |
| Shell、终端、作业工具 | 凑近绿色终端，提示符闪烁 |
| 子代理、协作者 | 轻轻摇摆，连接徽章跳动 |
| 等待批准或回答问题 | 慢速呼吸，徽章常亮，带输入提示，不闪烁提醒 |
| 回复成功完成 | 小跳一下加闪光，然后回到空闲 |
| 提示或 Agent 出错 | 轻轻摇两下，提示“看一下对话” |

- 动作来自真实的 Chat projection：进行中的工具调用和部分回复，加上会话的运行、错误和待处理交互状态。准备中的工具调用在派发前仍算“思考”。多个工具并发时以最近的活动调用为准，包括嵌套调用。
- 停止和报错不会触发庆祝。
- 每条消息对应真实活动，没有假进度，也不轮播闲聊。GPT 的文案干脆一些（如“理理思路…”），Claude 温和一些（如“想一想…”）。
- 动画是用 CSS 和道具让一张静态正面参考图动起来，不是逐帧精灵图或 Live2D 模型。

## 操作与偏好

- 拖动角色即可移动，位置限制在视口内并记在当前浏览器。收起后的 40px 状态按钮也可以拖动，不拖动直接点击则展开。
- 聚焦角色或收起按钮后，用方向键调整位置，按住 Shift 移动更大的步长。状态文字不拦截点击。
- 设置里有两种尺寸和一个动画开关，按 Esc 关闭设置。系统开启减少动态效果时同样生效。没有声音。
- 偏好（包括位置）保存在浏览器 localStorage 的 `dsh-ai-mascot:preferences`，不写入 profile，也不在设备之间同步。
- 齿轮按钮里可以看到素材来源。

## 外部请求与边界

- 两张参考图从 `selinlee.github.io` 加载，首次使用需要能访问这个站点，浏览器会向它发出普通的图片请求，不带对话内容或 referrer。图片加载失败时，模型名和活动仍然显示。
- 正面裁切图在浏览器内存里去掉与边缘相连的近白背景，保留封闭的白色细节。处理后的图片不打包、不上传。
- 没有 Host 进程、轮询或对话上传，不额外保留会话，不改模型，不执行工具。头部观察器不渲染界面，角色挂在附加的 `shell.overlay` 位置。
