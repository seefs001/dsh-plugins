把代码差异、AI 回复和用户自己历史消息的批注统一收口到输入框上方的标注托盘，发送下一条消息时由服务端 `agent/pre-step` 自动作为可折叠上下文行（`ContextInjectionRow`）隐式注入，既保留精准定位与短编号指代（`A1`、`A2`…），又不撑爆用户消息气泡。

## 使用方式

- **标注对话文字**：在 AI 回复或自己的消息里划词，浮动条并排显示「引用文本 | 标注」（也可在选中文本后按 `Cmd/Ctrl+Shift+A`）。选择意图标签（备注、修改、追问、修订、约束）并写下批注即可加入待注入托盘。
- **标注 Git 改动**（需启用 Forge 变更面板）：在右侧 diff 的行评论框点「加入标注」，或在文件菜单点「标注此文件」；已添加的标注会直接回显在 diff 行间。
- **管理与注入**：输入框上方托盘展示所有待注入标注，支持逐条勾选开关、点击跳回原文或对应 diff 文件、编辑、清空、从「已发送」历史重新加入，以及空草稿时一键「直接发送」。

## 注入与存储说明

- 仅在每轮首次模型调用（`step === 1`）且存在用户消息时，将勾选的 `draft` 标注整理为 `<user-annotations>` 结构块插入用户消息之前，不影响 System Prompt 与历史前缀缓存。
- 仅在 `session/event` 确认注入消息已写入会话日志后，才将对应标注翻为 `consumed`，避免被取消或拒绝的 step 丢失草稿。
- 数据通过 `@deepseek-ai/dsh-storage-domain` 按会话持久化，单会话上限 80 条、全局上限 120 个会话并在写入时自动裁剪。
