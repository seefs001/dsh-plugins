<PluginFacts slug="compaction-status" />

当 DSH 进行上下文压缩时，原生过程细节默认折叠在消息流里，不展开很难判断是不是卡住了。本插件在输入框上方显示一行与原生任务栏同宽的进度条，实时展示 **正在压缩上下文** 与已等待时间。

## 安装

<InstallCommand slug="compaction-status" />

## 工作方式与边界

- Host 端注册 `dsh-compaction-status` 会话投影，从 `compaction/start` 与 `compaction/end`（及轮次结束/分叉边界）维护当前状态。
- Web 端仅在压缩进行中显示，压缩结束后自动消失，无配置项与持久化存储。
- 只读展示进度，不主动触发压缩，也不改变压缩耗时长短。
