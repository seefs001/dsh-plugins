上下文压缩期间，在输入框上方居中显示与原生任务栏同宽的进度条，实时展示 **正在压缩上下文** 与已等待时间，压缩结束后自动消失。

## 安装

<InstallCommand slug="compaction-status" />

## 工作方式

- Host 注册 `dsh-compaction-status` 会话投影，从 `compaction/start`、`compaction/end` 及轮次/分叉边界折叠出当前压缩状态。
- Web 端按秒刷新已等待时间，无额外配置项与持久化存储。
