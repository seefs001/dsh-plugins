<PluginFacts slug="keep-awake" />

运行长时间 Agent 任务或定时调度时，防止 macOS 因为键盘鼠标无操作而进入闲置休眠，同时保留显示器自动熄灭和系统锁屏。

## 安装

<InstallCommand slug="keep-awake" />

仅在 macOS Host 上生效（无需管理员权限、配置项或外部依赖）。

## 工作方式与边界

- Host 启动时派生 `/usr/bin/caffeinate -i -w <host_pid>`：
  - `-i` 参数仅阻止系统闲置休眠，**不会**阻止显示器休眠、手动睡眠、盒盖睡眠或关机；
  - `-w <pid>` 绑定 Host 进程生命周期，停用插件或 Host 退出/崩溃后，系统自动释放电源断言，不改变任何永久电源设置。
- 在 Linux 或 Windows 上安装时，插件只记一条提示日志并保持空转，不会报错。
