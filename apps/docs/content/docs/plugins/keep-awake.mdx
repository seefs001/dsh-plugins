<PluginFacts slug="keep-awake" />

运行长时间 Agent 任务或定时任务时，阻止 macOS 因无操作进入闲置休眠，显示器仍照常熄灭和锁屏。

## 安装

<InstallCommand slug="keep-awake" />

仅在 macOS Host 上生效，无需额外配置。

## 工作方式

- Host 启动时派生 `/usr/bin/caffeinate -i -w <host_pid>`：
  - `-i` 仅阻止系统闲置休眠，不影响显示器休眠、手动睡眠、盒盖睡眠或关机；
  - `-w <pid>` 绑定 Host 进程 PID，停用插件或 Host 退出后自动释放电源断言。
- 在 Linux 或 Windows 上运行时仅记录警告日志并空转。
