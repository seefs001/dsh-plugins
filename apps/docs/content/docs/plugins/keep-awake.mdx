<PluginFacts slug="keep-awake" />

启用后，运行 DSH Host 的 Mac 不会因为闲置而自动休眠。显示器仍可熄灭，屏幕仍可锁定。不需要管理员权限、依赖或配置，也不改永久电源设置。

## 安装

<InstallCommand slug="keep-awake" />

需要 macOS 自带的 `/usr/bin/caffeinate`。插件作用于 Host 所在的电脑，不是浏览器所在的设备。在其他操作系统上，它记录一条警告，不做任何事。

## 使用

在 Plugins 页启用 **保持唤醒**，没有设置项和浏览器控件。停用插件或退出 DSH Host 就不再阻止休眠。关闭浏览器标签页不会停止后台的 Host。

## 生命周期

每个启用的插件实例启动一个 `/usr/bin/caffeinate -i -w <host-pid>` 进程：

- `-i` 阻止系统自动闲置休眠，接电源和用电池时都生效，不要求显示器保持点亮。
- `-w` 把断言绑定到 Host 的 PID。Host 退出时，包括崩溃或被强制结束，断言随之释放。
- 停用插件时，插件结束并等待这个进程退出。重新启用会启动新的进程。
- 进程是 unref 的，不会让本该结束的 Host 继续运行。
- 启动失败会让插件启用失败。进程意外退出时只记录日志，不自动重试；停用再启用即可重试。

在 macOS 上查看当前断言：

```bash
pmset -g assertions
```

启用时，`caffeinate` 应持有 `PreventUserIdleSystemSleep` 断言，而不是 `PreventUserIdleDisplaySleep`。停用后断言消失。其他应用或 DSH 进程仍可能独立阻止休眠。

## 限制

- 不阻止合盖、手动休眠、关机或电量极低时的行为。
- DSH 空闲时也让电脑保持唤醒，会增加耗电。不需要时请停用。
- 不改锁屏、显示器休眠、磁盘休眠或永久电源设置。
- 只有 Host 部分，不依赖 Web 界面，不添加工具、会话、定时器或网络请求。
