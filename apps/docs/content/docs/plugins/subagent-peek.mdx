当主会话派生了一个或多个子代理时，在会话标题右侧显示紧凑计数胶囊，无需切到右侧面板即可掌握全部后代子代理的运行与阻塞状态。

## 安装

<InstallCommand slug="subagent-peek" />

## 工作方式

- **实时状态胶囊**：显示当前会话的完整后代子代理数量（无子代理时隐藏）；有子代理在跑时前置脉动圆点，有任意子代理等待审批/提问或最近轮次失败时高亮提醒。
- **派生树速览弹窗**：点击胶囊弹出按原始派生顺序缩进排列的子代理树，展示名称、运行耗时、待处理类型、失败标红或未查看的完成圆点。
- **直达与侧看**：点击一行直接切入该子代理对话并清除该行未读圆点；点击行尾图标可在右侧分栏侧看。
