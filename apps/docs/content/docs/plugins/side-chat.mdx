---
title: 侧聊
description: 在主聊旁用相同的 Agent 预设单独追问，按需把引用带回主聊草稿。
---

<PluginFacts slug="side-chat" />

主聊继续工作时，点输入框下方的 **侧聊**，或从命令菜单选 `/side` 打开右栏。选中聊天正文后右键选 **在侧聊中提问**，会带上选区。输入第一问后才创建会话，未改动主聊草稿。

<InstallCommand slug="side-chat" />

侧聊沿用主聊当前的 Agent 预设，第一问通过 DSH 会话引用获取主聊上下文。后续对话只保存在侧聊；对话记录独立，工作区文件共享。

点 **引用到主聊草稿** 可把侧聊交回主聊，不自动发送。关闭右栏后可以从原主聊重开；只有显式归档才会将侧聊从列表中移除，归档后可通过提示条点击撤销恢复。
