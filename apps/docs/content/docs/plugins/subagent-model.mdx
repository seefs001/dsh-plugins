<PluginFacts slug="subagent-model" />

打开子代理的对话时，输入框右下角显示它记录的模型名和推理强度。标签是只读的，没有下拉箭头，也不能点击换模型。主代理的会话仍然使用原来的模型选择器。

## 安装

<InstallCommand slug="subagent-model" />

不需要额外的 API key、实验 bundle 或配套插件。

## 显示规则

- 模型来自子代理会话自己持久化的 `modelSelection` projection，先取 `next`，没有时取 `lastUsed`。不会用主代理或全局默认模型代替。
- 模型目录只提供易读的模型名和推理强度名。目录里没有的模型和强度显示原始 ID。
- 没有显式记录推理强度时，和主代理选择器一样显示目录声明的默认值。支持推理但没有声明默认值时，显示“提供方默认”。目录里的默认值只是显示信息，不代表 provider 实际用了它。
- 子代理还没有记录模型时，显示“尚无模型记录”。这不是请求失败，也不会套用主代理的模型。
- 悬停可以看到 provider/model ID 和只读说明。字号、高度、主题颜色和紧凑模式沿用内置标签。

## 原理与数据

插件在 `conversation.input.right` 注册自己的单元，排在快速模式按钮之后，不替换 `conversation.input.model` 或输入框。共享模型目录只用来读元数据，它的 `current` 选择不会被当作子代理的路由。

没有插件配置、自定义存储或浏览器偏好，不发起模型请求。Host 入口是空的。

## 排查

- 主代理会话里看不到新标签是正常的。要打开子代理自己的对话，而不只是工具调用摘要。
- 子代理里也没有标签时，确认 profile、bundle 是否启用和内置 UI 服务，然后刷新页面。
- 显示原始 ID 说明目录里没有对应元数据，不影响路由。

停用或移除这个插件即可恢复原界面，已有会话和模型设置不变。
