在子代理会话输入框右下角展示该子代理实际记录的模型与推理强度（只读），方便核对每个子代理运行在哪个模型上。

## 安装

<InstallCommand slug="subagent-model" />

## 显示规则

- 仅在子代理会话中渲染；普通主会话保持原生模型选择器不变。
- 读取当前会话 `modelSelection` projection（优先 `next`，其次 `lastUsed`），结合模型目录展示名称与推理强度（如 `GPT-6.1 Sol · High`、`GPT-6.1 Sol · 提供方默认` 或 `尚未记录模型`）。
- 悬停标签可查看完整的 `provider/model` 路由。
- 无配置项与存储，不改动子代理路由。
