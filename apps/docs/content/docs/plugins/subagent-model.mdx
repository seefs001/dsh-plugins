在子代理会话中，输入框右下角不显示主会话的可编辑模型选择器。安装本插件后，同一位置会显示该子代理实际记录的模型名称与推理强度（只读），方便核对每个子代理究竟跑在哪个模型上。

## 安装

<InstallCommand slug="subagent-model" />

## 显示规则

- 仅在子代理会话中渲染；普通主会话保持 DSH 原生模型选择器不变。
- 读取当前会话 `modelSelection` projection（优先 `next`，其次 `lastUsed`），结合模型目录解析模型名称与推理强度名称：
  - 已记录推理强度：`GPT-6.1 Sol · High`
  - 使用提供方默认强度：`GPT-6.1 Sol · 提供方默认`
  - 尚未产生记录：`还没记录到模型`
- 鼠标悬停标签可查看完整的 `provider/model` 路由及只读说明。

## 边界说明

- 纯 Web 展示插件（Host 入口仅用于加载 bundle），没有配置项或存储数据。
- 只读显示，不改变子代理的实际模型路由或权限。
