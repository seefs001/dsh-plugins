悬停自己发出的消息点击铅笔图标，即可在当前会话就地改写正文（默认清空后续模型上下文），或分叉出新会话重发。

## 安装

<InstallCommand slug="message-edit" />

## 编辑模式

| 模式 | 效果 |
| --- | --- |
| **在当前会话修改**（默认勾选 **清空后续上下文**） | 用 `replace` 节点替换该消息并清除后续模型上下文；界面记录保留，不自动重新回答 |
| **在当前会话修改**（取消勾选 **清空后续上下文**） | 仅替换该消息文本，保留后续对话与工具结果上下文 |
| **分叉并重发** | 从该消息前最近的已结束轮次分叉出新会话并发送改写后的消息，原会话不变 |

仅编辑消息纯文本，原有图片与文件附件保留在原位；改写过的消息会标注 **已编辑**。若消息已因压缩移出上下文，可使用 **分叉并重发**。清空上下文只影响模型后续可见历史，不会撤回已执行的磁盘或终端操作。
