发现上一条提示词写错了或者想换个指令时，悬停自己发出的消息点击 **编辑**（铅笔图标），直接修改正文。默认在当前会话就地改写并清空后续上下文，不必每次都另开新会话。

## 三种编辑模式

| 模式 | 操作结果 |
| --- | --- |
| **在当前会话修改**（默认勾选 **清空后续上下文**） | 用原生 `replace` 节点替换该消息并从模型上下文里清除之后的消息与工具结果；界面聊天流依然保留可见记录，且**不会自动重发请求**，由你决定接下来怎么说 |
| **在当前会话修改**（取消勾选 **清空后续上下文**） | 仅替换该条消息文本，保留后面的对话与工具结果上下文 |
| **分叉并重发** | 从该消息之前最近一次已结束轮次分叉出新会话，并自动发送改写后的消息，原会话保持原样 |

## 边界说明

- 仅编辑消息的纯文本块，原有的图片与文件附件会保留在原位；不支持保存空白消息。
- 已编辑过的消息旁边会标注 **已编辑**。
- 如果该消息已经因上下文压缩被移出当前模型上下文，就地修改将不可用，此时可改用 **分叉并重发**。
- 清空上下文只改变模型后续看到的会话历史，不会撤回磁盘上或终端里已经执行过的操作。
