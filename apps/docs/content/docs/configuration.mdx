大多数插件在界面里配置。你在界面上的操作由插件通过 DSH 的 config editor 写回 profile，重启和升级后保留，不需要手改 YAML。

## 每个插件保存什么

| 插件 | 内容 | 位置 |
| --- | --- | --- |
| # 引用模型 | 每个 `provider/model` 上次的推理强度 | profile 中该插件的 `efforts` 配置 |
| 快速模式 | 开启 ⚡ 的 `provider/model` | profile 中该插件的 `tiers` 配置 |
| 记住上次模型 | 新会话的默认模型和推理强度 | DSH 自己的 `agent-default-model` 配置 |
| 自动审查模型 | 审查模型、推理强度、提示词模式和提示词 | profile 中该插件的配置 |
| 自动审查模型 | 每个会话的审查记录 | Host 的 `auto_review_log` storage domain |
| 会话分组 | 分组、成员、组顺序和组内置顶 | Host 的 `session_groups` storage domain |
| Wait, what? 回复解释 | 专用模型的 `provider`、`model`、`reasoningEffort` | profile 中该插件的配置 |
| Wait, what? 回复解释 | 最近 200 份完整解释 | Host 的 `message_actions` storage domain |
| 联网搜索 | 每个搜索工具的开关、模型、搜索类型和超时 | profile 中该插件的配置 |
| Pi 工具 | 预设配置；每个会话选择的工具 | 预设随 bundle 提供；工具选择写入会话日志的 `agent-preset/options` 事件 |
| Switchboard | 中继地址、工作区别名、权限映射等 | profile 中该插件的配置，需手动编辑 |
| Switchboard | 未确认的帧、会话绑定、隔离标记；待上传的产物 | Host 的 `switchboard_connector` storage domain；`dataDir/blobs` 下的文件 |
| AI 吉祥物 | 位置、尺寸、收起状态和动画偏好 | 浏览器 localStorage 的 `dsh-ai-mascot:preferences` |

其余插件没有自己的配置或存储：最近会话优先、子代理模型、上下文压缩状态、引用跳转、工具透镜、Git 变更、分支切换、工作区管理和保持唤醒。上下文压缩状态从原生会话事件派生一个 projection，不另存记录。工作区管理和分支切换只调用 DSH 原生的工作区接口和 Git，不保存自己的状态。

## storage domain 在哪里

使用默认 JSON 后端时，storage domain 的文件在 `~/.dsh/storages` 下，例如 `session_groups.json`。审查日志使用 per-record 布局，每个会话一个 JSON 文档。实际位置取决于 Host 的 storage domain 配置。这些插件需要 `@deepseek-ai/dsh-storage-domain`，默认 profile 已经包含。

移除插件不会清掉这些文件。

## 审查日志与隐私

自动审查模型的日志每个会话最多保留最近 200 条，最多保留最近 300 个会话。工具参数截断到 4000 个字符，理由截断到 2000 个字符。参数里可能有敏感值。日志只存在这台 Host 上，在审查日志弹窗里点 **Clear** 可以删除当前会话的记录。

Wait, what? 回复解释的提示词和结果以明文保存在 Host。生成时，所选回复和它之前最近一条用户消息会发给所选的模型服务。

## 读懂配置片段

插件页里的 YAML 只展示插件行的 `id` 和 `config`，用来说明结构：

```yaml
- id: service-tier
  config:
    tiers:
      responses/gpt-6.1-sol: priority
```

安装 bundle 时已经插入了这一行，不要再手动插入一份。需要手改时，在 profile 的 `cordis.patch.yml` 里修改已有行的 `config`。

## 凭据

联网搜索复用 `llm-pi-ai` 中 Responses provider 的 `baseURL`、`apiKeyEnv` 和 `headers`，插件只保存 provider、模型和搜索选项。Switchboard 的 token 通过 `tokenRef` 引用，先查 DSH 凭据，再查同名环境变量。

不要把密钥写进文档、仓库或示例配置。provider 的 key 必须能在运行 Host 的环境里解析。

## 多个浏览器之间如何同步

- 记住上次模型保存默认值后，会发出模型列表更新事件，已连接的浏览器随后刷新默认模型。
- 会话分组由 Host 保存，通过 SSE 把完整状态推给打开的页面。
- Wait, what? 的缓存在 Host 上，多个浏览器共用。
- AI 吉祥物的偏好只在当前浏览器里，不会同步。
