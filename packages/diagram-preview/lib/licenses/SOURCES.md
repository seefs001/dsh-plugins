The browser distributions are copied unmodified into local DSH chunk wrappers. The bundled license comments remain in the source strings.

- [Mermaid](https://github.com/mermaid-js/mermaid), MIT. See Mermaid.txt.
- [Apache ECharts](https://github.com/apache/echarts), Apache-2.0 with bundled D3 components. See ECharts.txt, ECharts-NOTICE.txt and ECharts-d3.txt.
- [Viz.js](https://github.com/mdaines/viz-js/tree/c8ce050d28eb0dc1ed1629ea32ab7f3dc117db0f), MIT. The WASM distribution contains [Graphviz 16.1.0](https://gitlab.com/graphviz/graphviz/-/tree/16.1.0), EPL-2.0, and [Expat 2.8.5](https://github.com/libexpat/libexpat/tree/R_2_8_5), MIT. See Viz-js.txt, Graphviz.txt and Expat.txt.
