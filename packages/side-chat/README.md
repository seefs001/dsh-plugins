# dsh-side-chat

在右栏开一个独立的 DSH 会话，用主聊的上下文追问。新侧聊沿用主会话的 **Agent 预设**与工作区；对话记录独立，文件改动共享。

## 使用

- 点主聊输入框下方的 **侧聊**、从命令菜单选择 `/side`，或选中聊天正文后右键选 **在侧聊中提问**。
- 输入第一问后才创建会话（支持 `⌘/Ctrl + Enter` 发送）。第一问携带主聊的原生会话引用与选中文本，之后直接在右栏的原生输入框继续追问。
- 关闭面板或切换右栏标签页会保留当前侧聊状态；点 **归档侧聊** 将其从侧聊列表移除，并支持通过提示条一键撤销恢复。
- 点 **引用到主聊草稿** 会把当前侧聊的会话引用插入主聊输入框，不自动发送。

## 本地安装

从仓库根目录运行：

```bash
dsh plugin --profile web add "link:$PWD/packages/side-chat"
```
