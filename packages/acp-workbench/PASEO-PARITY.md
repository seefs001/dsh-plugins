# Paseo 本体与 DSH 插件：行为对照

参考的是 [getpaseo/paseo](https://github.com/getpaseo/paseo)，不是 Hub，也不是带定制功能的 fork。以下源码路径以可复查的官方 [`b95f1bb`](https://github.com/getpaseo/paseo/tree/b95f1bbf3152e688584d3ad00358b65d7ac78bcd) 为基线。对照时远程 `main` 已到 `c8e3d67`；两者间的 20 个提交没有修改下述 creation、workspace registry、agent profiles、workspace scripts 或 new-workspace-launch 路径。目标是让人在 DSH 完成同一件事，而不是移植 Expo、再开一个 daemon，或声称两个产品的协议兼容。

| 用户要做的事 | Paseo 的实现入口（仓库内） | DSH 的实现、差异与剩余工作 |
| --- | --- | --- |
| 选择项目，开多个 agent | `packages/server/src/server/workspace-registry-model.ts`、`server/creation/index.ts`、`packages/app/src/new-workspace-launch/` | 工作台「项目」读 DSH 工作区与会话目录，支持添加本机目录。在同一项目创建多个独立会话，不占用已有空白对话；打开后才发第一条消息。DSH 工作区是项目入口；没有复制 Paseo 的两层注册表。|
| 从多个项目找到 agent，改名并在以后找回 | `packages/app/src/command-center/workspace-search.ts` 的 `agentSearchFields`、`screens/workspace/use-workspace-tab-rename.tsx`、`workspace-rename/internal/set-workspace-title.ts`（后两路径在 `packages/app/src` 下） | 项目页可按项目/会话、已知引擎、目录或原生会话 ID 组合筛选；复用 DSH 的会话菜单改名/置顶，从原目录快照恢复，不复制标签页或创建索引。工作区改名只更改注册表标题。仅检索已注册项目成员的元数据，不是跨主机指令面板或聊天全文检索。 |
| 一次收起几个 Agent，稍后找回 | `packages/app/src/screens/workspace/workspace-bulk-close.ts` 和 `workspace-screen.tsx` 的 `handleBulkCloseTabs` 对不同标签分类确认；`packages/app/src/hooks/use-archive-agent.ts` 维护 Agent 归档及历史列表 | 在 DSH 当前项目勾选具名会话，逐项使用 DSH 原生归档/恢复；变更前检查归属和归档方向，活动或等待审批的会话不强停，工作树另走单项确认。保留会话及 CLI 身份，部分成功单独报告。不是“关闭其他”标签布局，不关闭终端、不销毁工作区，也不复原置顶状态。 |
| 隔离开发，不改原 checkout | `packages/server/src/server/session/workspace-provisioning/`、`server/worktree/` | 本机目录或 DSH 托管的新分支 worktree；可指定本机已有的起始 ref。ACP 实际进程目录、`session/new` 和 CLI 历史查询使用会话生效的工作目录。现有外部上下文不能跟随目录悄悄转移。「工作目录」按 DSH 创建记录和文件系统分别显示来源、分支、起点提交、实际目录是否存在及本次 Host 的回收结果。干净且无人使用的 checkout 可能被 DSH 回收；用户恢复会话后可显式重建缺失 checkout，分支缺失时只回到起点提交。对于还指向缺失或不完整托管目录的 ACP 会话，阻止 DSH 在组装提示时自动回到源项目，包括首次发送。不会强删工作树、移植销毁钩子或更改全局保留策略。对照 `server/workspace-archive-{service,operations}.ts`；不等同于从 PR 创建工作区或自动合并。|
| 让多个 Agent 在同一 checkout 工作 | `server/agent/tools/paseo-tools.ts` 的 `resolveCreateAgentWorkspace`、`packages/app/src/workspace-tabs/` | 从已有托管工作树选择引擎创建新的 DSH 根会话。Host 复核项目、创建记录及 Git 登记，借用方共享文件，不复制聊天、CLI 会话或审批，不获得 checkout 所有权。项目页和聊天内均可切换参与者。只列创建者和经此入口加入且仍在使用该路径的会话，不接管任意外部目录、其他终端或工作区级销毁。|
| 重复使用启动设置 | `packages/app/src/agent-profiles/internal/materialize-profile.ts` | 跨项目保存具名提供方、模型、已公布的思考强度和隔离方式。选择后可改；保存或删除不修改任何已启动会话，不保存提示词、权限或密钥。CLI 权限模式仍在当前会话单独设置。|
| 并行工作、停止、继续、找回历史 | `packages/server/src/server/agent/agent-manager.ts`、`packages/app/src/workspace-tabs/`、`packages/app/src/subagents/` | DSH 会话树、原生子代理、消息队列和 Stop；ACP 绑定与外部 session ID 持久化。CLI 公布 load/resume 时支持无提示接续。项目入口使用 DSH 原生归档/恢复，工作台记录归档和 DSH 会话归档不是同一回事。没有移植 Paseo 分栏拖拽布局。|
| 从已有上下文另试一种做法 | `packages/app/src/hooks/use-fork-agent.ts`、`packages/app/src/components/assistant-fork-menu.tsx` | Paseo 可按消息边界将聊天历史附到草稿；DSH 的不同实现是从同一目录的 CLI 历史，显式 `session/fork` 最新已保存上下文到一个未绑定的 DSH 会话。不接管原 CLI ID，复制后不发提示词，独立持久化和恢复。需要 `list`、`fork` 和 `loadSession`/`resume` 能力，不支持任意消息锚点、流式中间态或跨提供方复制。 |
| 回答 Agent 的单选、多选或补充问题 | `packages/app/src/components/question-form-card-core.ts` 解析 `options`、`multiSelect`、`allowOther`、`allowEmpty`；同目录 `question-form-card.tsx` 呈现选项和示例 | 在现有 DSH 请求卡片呈现 Claude ACP `AskUserQuestion` 生成的会话级表单。按字段显示必填、说明、单选/多选、文字和只读示例；用户决定提交、拒答或取消。撤回按同一连接的 RPC 请求 ID 匹配，不回答其他并发提问。只支持这里列出的表单类型，不接管外部 URL、凭据、任意 JSON Schema 或独立的 CLI 子会话；不把回答当作执行授权。 |
| 了解 CLI 警告、工具不可用或模型回退 | `packages/app/src/agent-stream/view.tsx` 的通知分支和 `components/message.tsx::Notification` 按 info / warning / error 渲染通知，不把它当成助手回答 | DSH 执行轨迹按收到顺序显示明确的 ACP `notice`；输入框下方显示当前连接最近八条轮次外提醒。保留提供方级别、说明、接收时间和明确的任务来源。提醒不改变审批、运行结果或模型选择；这是本地界面，不是推送或已读回执。 |
| 看见 CLI 压缩对话，查看它保留了什么 | `packages/app/src/components/message.tsx::CompactionMarker` 和 `message-compaction-label.ts` 区分进行中、自动、手动及压缩前 token 数 | DSH 执行轨迹按 ACP 的压缩 ID 原位更新状态、可读摘要、取消和错误。支持安装版 Claude 的标准回报及明确标识的旧 `compact` 工具；触发方式、前后计数和耗时有来源才显示。回放另列；这不会压缩 DSH 自己的消息，也不根据占用下降猜测触发。 |
| 查看上下文占用和当时的会话用量 | `packages/app/src/components/context-window-meter.tsx` 和 `context-window-details.tsx` 将窗口占用、无数据状态和可选会话费用分开展示 | DSH 输入框旁只列当前绑定 CLI 的最近实报；展开看数值、时间和可选费用/模型。执行轨迹保留各轮当时的窗口和提示结束时返回的 ACP 会话累计计数。不会用累计数再记一次 DSH 单请求用量，不估算余额，不轮询提供方账号，也不执行压缩。 |
| 一边看任务进度，一边查看方案正文 | `packages/app/src/utils/tool-call-parsers.ts` 的 `extractTaskEntriesFromToolCall` 区分 `TodoWrite`/`update_plan` 与 `ExitPlanMode`；`server/agent/providers/claude/agent.ts` 单独处理计划审批 | DSH 原生聊天的轨迹区分清单、CLI 报告的 Markdown 正文和移除通知。新版 ACP 按 `planId` 整份替换，旧 `plan` 与 Cursor 待办仍可读。只显示本轮报告的状态，不从工具名拼造计划、从正文推断批准或维护跨轮可编辑待办板。 |
| 区分 CLI 内部任务和可接续的子代理 | `server/agent/providers/claude/agent.ts`、`server/agent/provider-subagents/store.ts`、`packages/app/src/panels/provider-subagent-panel.tsx` | 在原 DSH 轨迹中按 Claude ACP 报告的启动调用 ID 关联直接调用、任务进展、子计划和权限回执。多个启动调用可从同一个索引切换；嵌套任务可逐层查看，完整轨迹保留原时序。启动调用完成不等于后台进程已退出。任务中的文本、思考和图片不再混入新一轮父会话回复。其他 CLI 没有报告相同元数据时保留普通工具行；没有创建 DSH 子会话、独立发送/取消入口或跨轮的后台任务注册表。|
| 知道谁在等我、回答请求 | `packages/app/src/utils/agent-attention.ts`、`packages/server/src/server/agent-attention-policy.ts` | 项目审阅分别列出当前项目根会话及其子代理的待回应请求和已结束的 ACP 轮次。成功、失败、中断均可审阅；用精确的运行 ID 标记，不影响后续轮次或审批。已读存于 Host；旧记录不追补成未读。DSH 采用显式标记，不等同于 Paseo 的焦点自动清除、跨设备推送或 Desk 协调。|
| 核对 agent 做了什么 | `packages/app/src/agent-presentation/`、`packages/app/src/agent-stream/` | 原生聊天时间线映射 ACP 的读、搜、改、终端、网页、计划、交互；来源不明时保留原文。项目结果可看最终回复摘录、该轮报告过的 diff 路径和工具数，展开同一个原生轨迹。对照 `packages/app/src/tool-calls/detail-level/{grouping,projection}.ts` 与 `overview/model.ts`，提供可展开的连续查阅摘要和逐条视图。比上游更保守，只合并已完成且无单独审批、diff 或非文本输出的读、搜和网页调用。消息/思考边界保留但不重复展示文本。根据真实请求和决定关联权限标签；没有关联 ID 时只保留原事件。事件是展示证据，不会重放执行。|
| 分清哪个 MCP 服务收到了哪些参数、返回了什么 | `packages/server/src/server/agent/providers/codex/tool-call-mapper.ts` 的 `mapMcpToolCallItem`、`splitCodexMcpToolResultImages`；`packages/app/src/components/tool-call-details.tsx` 的 `buildUnknownSections` | DSH 聊天和活动记录区分服务、工具、参数与输出；混合媒体按原顺序展示，结构化列表可按行查看。审批卡区分实际参数和 CLI 的展示说明。已用本机 Claude 适配器和按 Codex 源码构造的离线回报验证；不连接、配置或代替 CLI 调用 MCP 服务。 |
| 核对 agent 搜了什么、抓取了哪一页 | `packages/app/src/components/tool-call-details.tsx` 的 `FetchDetailSection` 和 `buildSearchSections`、`packages/server/src/server/agent/providers/codex/tool-call-mapper.ts` 的 `mapWebSearchItem` | 区分网页搜索、抓取、页内查找。Claude ACP 的查询、域名限制、提取要求和来源分开显示，保留说明与命中原顺序。Codex ACP 的 `search`、`open_page`、`find_in_page` 仅代表调用参数。未报告的命中、HTTP 状态或正文不推断；工具报错不会被识别为搜索结果，展开不联网。 |
| 在聊天里跟进命令输出 | `packages/app/src/components/tool-call-details.tsx` 的 `ShellDetailSection`、`server/agent/providers/codex/tool-call-mapper.ts` 的 `mapCommandExecutionItem` | 工具行使用 DSH 终端组件，只展示报告，不创建 PTY。支持 Claude ACP v1、Codex ACP 各自的分段规则；能在原生轨迹和历史活动里看终端文本、单独报告的汇总结果、明确的退出码或信号。每次调用的流式预览保留末尾 32 Ki 字符，原始事件不丢。未知适配器不猜重复分包的含义；不能接管 CLI 进程，也没有跨轮后台终端注册表。|
| 查看一个编辑调用里的多文件补丁 | `server/agent/providers/codex/tool-call-mapper.ts` 的 `fileChangesToPreview`、`packages/app/src/components/tool-call-details.tsx` 的 `useDiffLines` | 聊天、历史轨迹及审批卡按文件查看同一调用报告的 ACP diff 片段，可切回完整片段顺序。单独标明启动预览、审批请求、更新、完成或失败回报的来源，仅有完成状态不会改变补丁来源。支持 Codex ACP 在同帧提供的 `changes` 操作，包括仅移动且无结构化文本差异；不从空旧侧或空新侧推断增删文件。不执行补丁，不把它当作当前磁盘快照。|
| 按文件名找到 agent 写的文件 | `packages/app/src/command-center/workspace-file-search.ts` 的 `useWorkspaceFileSearch`、`workspace-file-search-model.ts`、`screens/workspace/workspace-file-open-command.ts` | 项目会话行按生效工作目录调用 DSH 文件名搜索。空查询不扫描；可按文件名或路径查找，包括未跟踪文件，排除隐藏和 Git 忽略项。显示结果/扫描上限，选择后才预览或跳转到原会话侧栏。不是文件正文检索，不提供空查询的全目录建议。 |
| 不知道文件名时查找工作树里的产物 | `packages/app/src/components/file-explorer-pane.tsx`、`packages/app/src/file-explorer/directory-listings.ts` 的 `loadExplorerDirectory` 和请求代次检查 | **查找文件 → 浏览目录** 对选中会话的实际工作目录逐层调用 DSH `workspaceFiles.list`。可看目录、文件和返回的大小，按上方路径返回；空目录、截断和失败分别提示。只读，不递归扫描，不显示隐藏项，不沿改指其他路径的目录别名跳转；不是工作树历史快照或文件增删改入口。 |

`server/…` 是 `packages/server/src/server/…` 的缩写。本表以使用流程为粒度，不按按钮或源码行数计算“完成百分比”。

## 本地启动的不变量

1. 先检查当前注册的项目、提供方、模型和隔离能力。参数不合法不创建会话。
2. DSH 创建并持久化新会话 → 可选：创建并进入工作树 → 写会话名和本会话的模型选择 → 客户端打开普通聊天。没有隐式 prompt，也不改默认模型。
3. DSH 已创建会话后如果准备失败，返回可恢复的会话 ID 和错误，不删除它、不自动重试、不在原目录降级执行。归档则复用 DSH 的工作树保留/清理规则。
4. 启动配置是配置快照，不是 agent 身份。注册表拥有项目和会话身份；CLI 只在首次连接或发消息时获得独立的外部上下文。
