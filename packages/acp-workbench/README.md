# dsh-acp-workbench

在 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（DSH）原有会话中接入本机 ACP（Agent Client Protocol）CLI，或通过原生子代理工具委派可续聊的 ACP 子任务。默认预设 **Cursor**、**Antigravity** 与 **Claude Code**，支持添加任意兼容 ACP v1 的本机 CLI。

本插件不替换 DSH 的输入框、时间线、附件、停止按钮、子代理树、工作区、Git 或终端系统，也不依赖 Paseo daemon 或 Hub。

## 界面入口与执行模式

### 三个界面入口

| 入口 | 位置 | 作用 |
| --- | --- | --- |
| 模型选择器与 **CLI 设置** | 会话输入框底部 | 切换 ACP 模型与思考强度；打开浮动面板配置 CLI 模式、选项、命令或接续 CLI 历史 |
| **执行轨迹**与交互区 | 消息时间线与输入框上方 | 折叠/展开每轮工具调用、补丁、终端输出、计划与压缩；在输入框上方处理审批、提问、上下文占用与子任务 |
| **ACP 工作台** | 左侧边栏 | 分三页管理：**项目**（启动、审阅、文件、终端、脚本、定时任务）、**活动**（跨会话关注索引）与 **提供方**（CLI 配置与模型目录） |

### 两种执行模式

| 模式 | 触发方式 | 适用场景 | 工具与上下文 |
| --- | --- | --- | --- |
| **直接执行** | 在原模型选择器选择 `acp-*` 提供方下的模型 | 把整条 DSH 会话交给外部 CLI 执行 | 使用外部 CLI 自己的工具与权限；同会话切回普通 DSH 模型时自动交接历史文本 |
| **DSH 委派** | 保留普通 DSH 主模型，调用 `subagent_cursor`、`subagent_antigravity` 或 `subagent_acp_claude_code` | 由 DSH 主代理编排、并行委派或需要继续使用 DSH 工具/MCP | 创建原生可续聊 DSH 子会话；用 `send_message` 续聊，在父会话输入框上方直接审批 |

## 安装与准备

### 1. 安装插件

从 GitHub 安装到目标 profile（以 `web` 为例）：

```bash
dsh plugin --profile web add "github:seefs001/dsh-plugins#main&path:/packages/acp-workbench"
```

本地开发时从仓库根目录链接：

```bash
dsh plugin --profile web add "link:$PWD/packages/acp-workbench"
```

`cordis.patch.yml` 会自动挂载本插件及三个子代理工具路由（`subagent_cursor`、`subagent_antigravity`、`subagent_acp_claude_code`）。其中 `subagent_acp_claude_code` 与 DSH 内置的非 ACP 工具 `subagent_claude_code` 并存。

### 2. 准备并检查本机 CLI

1. 在终端安装并登录对应 CLI。
2. 打开侧栏 **ACP 工作台 → 提供方**，核对可执行文件与参数：

| 默认 ID | 名称 | 默认命令（优先 `~/.local/bin/`，否则取 `PATH`） | 默认参数 |
| --- | --- | --- | --- |
| `cursor` | Cursor | `cursor-agent` | `["acp"]` |
| `antigravity` | Antigravity | `agy` | `["acp"]` |
| `claude-code` | Claude Code | `claude-agent-acp` | `[]` |

3. 填写绝对工作目录后可点击：
   - **检查能力**：只运行 ACP `initialize`，展示协议版本、登录方式与能力标签，不发送模型任务。
   - **刷新模型**：新建空 ACP 会话读取候选模型并缓存元信息（能力、上下文窗口、输出上限、思考强度），不发送任务，也不自动修改主选择器。勾选需要显示的模型后点击 **保存模型选择**。
   - **查找 CLI 会话**：通过 `session/list` 浏览该目录下的既有 CLI 会话并导入为本地记录。

> 保存提供方、刷新页面或启动 Host 都不会自动启动外部任务。切勿把密钥或令牌填入命令行参数。

## 核心功能

### 1. 会话内直接执行

- **模型与思考强度**：主选择器仅显示你勾选保存的模型及 `CLI default`（沿用 CLI 当前模型）。选择具体模型与思考强度时，插件在发消息前通过 `session/set_model`、`thought_level` 或 Cursor 已公布变体完成切换；CLI 拒绝时不发送提示词。
- **CLI 设置浮层**：点原模型菜单中的 **CLI 设置**，可在输入框上方调整 CLI 公布的模式与选项、查看用量、快捷打开右侧工作区面板（文件 / Git 改动 / 新建终端）、运行 CLI 命令，或管理绑定。
- **接续与复制 CLI 历史**：首次发送前打开 **CLI 设置 → 接续 CLI 会话**，可列举当前工作目录下的历史会话：
  - **在这里接续**：仅连接旧上下文（优先 `session/load` 读取前文，不重播为 DSH 新消息，也不附上此前的 DSH 对话）。若该记录已绑定其他 DSH 会话，则直接跳转原会话。
  - **从副本继续**：在当前目录另开一个未绑定的 DSH 会话，当 CLI 同时支持 `session/list`、`session/fork` 与恢复能力时，可复制其最新已保存历史创建独立副本，原会话不变。
- **`/cli:` 命令补全**：当前连接空闲时，在输入框行首输入 `/` 可从 CLI 分组选择 `/cli:<命令>`。选中只插入标签，补全参数并发送后按普通文本交给外部 CLI，不触发 DSH 同名命令。
- **可折叠执行轨迹与最终回复**：每轮回答旁附带默认折叠的 **执行轨迹**（展开后底部也提供 **收起轨迹**），按时间顺序呈现外部事件；同时 ACP 轮次执行结束后会在回答末尾提供 **收起结果 / 展开结果** 切换（按当前浏览器记住折叠状态，折叠后收成一行摘要并支持页面内查找自动展开）：
  - **工具调用（概览 / 逐条）**：概览模式将连续完成的读取、搜索与网页查询合并为查阅摘要，正在执行、失败、审批、命令和编辑仍单列。
  - **写入与多文件补丁**：区分 Claude 的 **写入文件**（查看请求写入正文或补丁）与 **编辑文件**；多文件补丁支持按文件筛选与 **全部报告片段**，并标明补丁来源阶段（启动预览 / 审批请求 / 更新 / 完成 / 失败）。
  - **命令、MCP 与联网工具**：显示只读终端卡（流式输出保留末尾 32 Ki 字符与退出码/信号）、MCP 服务与工具的参数/结构化结果，以及分开展示查询/目标/来源的网页搜索、抓取和页内查找。
  - **CLI 内部子任务**：当 Claude ACP 报告 `_meta.claudeCode.parentToolUseId` 时，可切入只读的 **本轮 CLI 子任务** 视图查看其调用、进展与审批回执，不创建第二条 DSH 会话。
  - **计划、压缩、提醒与用量**：只读展示任务清单与 Markdown 方案正文、CLI 上下文压缩状态与摘要、`notice` 提醒（轮次外最近 8 条显示在输入框下方）、窗口占用报告与轮末累计 token 总量。
- **人工交互与新建上下文**：权限审批、Agent 提问、Claude `AskUserQuestion` 表单（`elicitation/create`）与计划审批都在输入框下方完成；审批卡支持展开 **查看最初的工具调用** 核对启动上下文，历史轨迹只读回看。**新建外部上下文** 仅退役当前绑定，保留 DSH 消息与旧记录。

### 2. 项目工作台（侧栏：ACP 工作台 → 项目）

以 DSH 已保存的工作区为项目入口，整合多 Agent 协作、检查与启动流程：

- **启动与复用配置**：选择工作区或 **添加目录**，点击 **新建 Agent** 选择引擎、模型、思考强度与隔离方式（**使用项目目录** 或 DSH **独立工作树**，可指定新分支与起点 ref）。常用组合可保存为跨项目复用的 **启动配置**。
- **共享工作树协作**：展开托管工作树会话的 **工作目录 → 在这里新建 Agent**，可让多个 Agent 直接编辑同一份代码，同时保持各自独立的 DSH 会话、外部 CLI 上下文、审批与停止控制；聊天与项目页内均可 **切换同工作树 Agent**。
- **会话检索与批量整理**：支持按名称、项目、引擎、目录或 DSH 会话 ID 在 **当前项目** / **全部项目** 搜索，筛选 **只看置顶**，以及按清单逐项执行 **批量归档会话** / **批量恢复会话**（活动、待回应或含工作树记录的会话跳过）。
- **文件查找与目录浏览**：在会话行打开 **查找文件**，按该会话生效工作目录 **按名称查找**（排除隐藏项与 Git 忽略项）或 **浏览目录**（逐层查看可见文件与目录，含未隐藏的构建产物等 Git 忽略项），点击可预览并在原生文件侧栏打开。
- **会话终端与项目脚本**：
  - **会话终端**：实时列出该会话保留的用户/Agent 终端，一键定位或新建绑定标签。
  - **项目脚本**：读取该会话生效目录下的 `paseo.json` `scripts`，在会话沙箱终端中运行或停止；对读取 `$PASEO_PORT` 且未设固定端口的服务，支持 **带回环端口启动**（分配空闲端口与 `HOST=127.0.0.1`）及按需 TCP **监测端口**。
- **工作目录检查与恢复**：查看托管工作树的创建记录、分支、起点提交与回收状态；恢复已归档会话后，如目录缺失可显式 **重建缺失的工作树**（优先检出原分支，分支不存在时从起点提交重建）。
- **项目审阅与 Git 对比**：按项目汇总待回应请求与已结束轮次（**待审阅** / **全部结果**），支持回复摘录、本轮轨迹、**标为已审阅**，以及基于 DSH Forge 的 **工作树改动**（未提交 / 已暂存 / 未暂存 / 分支对比 / **分支上的提交**与范围对比，含补丁左侧查看旧行与按范围读取完整旧版本）。
- **定时任务**：基于 DSH 原生调度能力，在项目内创建、立即投递、暂停/恢复、查看投递历史或删除定时任务，支持唤醒已有会话、首次新建后复用或每次新建。

### 3. 活动索引（侧栏：ACP 工作台 → 活动）

跨所有 ACP 绑定按关注优先级分组：**等你回应**、**进行中**、**需查看**、**最近活动** 与 **历史**（已归档或已退役）。支持搜索、直接跳转原 DSH 会话，或打开详情页重命名、连接/断开、停止本轮及分页查看原始 RPC 事件。

## 权限、上下文与限制

- **沙箱与权限边界**：外部 CLI 使用自身的登录态、计费、工具集与文件权限，**不受 DSH 工具沙箱限制**。插件仅处理 CLI 实际发起的权限与交互请求；仅当所属 DSH 会话显式使用完全访问预设（`danger-full-access` 且 `approval: never`）且 CLI 提供 `allow_once` 时，才自动允许单次请求；持久授权、提问与计划审批始终由人工确认。
- **能力范围**：不透传 DSH 的 MCP 服务器，也不向 CLI 宣告 ACP 客户端 `filesystem` 或 `terminal` 能力。
- **上下文交接与恢复**：
  - 每个 DSH 会话与每个 ACP 提供方一一绑定；分叉创建独立远端会话。
  - 首次使用或从普通 DSH 模型切入时，仅把缺失的历史文本以分隔上下文标签交给 CLI（不把历史工具输出当作系统指令），单次交接上限 **200,000 字符**，超限明确拒绝而不静默截断。
  - 断开、重开会话或冷子任务续聊时优先调用 `session/resume`，仅在显式返回方法未找到（`-32601`）且支持 `loadSession` 时回退 `session/load`。
  - Host 重启后，中断的运行标记为 `interrupted`，不会自动重发不确定是否已执行的外部请求。
- **辅助路由与旧工具**：ACP 路由不承担标题生成、DSH 压缩等 `purpose` 工具调用。模型工具 `acp_workbench` 保留用于高级诊断与旧式独立记录；绑定到 DSH 会话的记录对其只读（`get` / `events`），不能替代原生子代理委派或人工审批。
- **错误处理**：CLI 对单轮提问或配置返回 JSON-RPC 错误时，仅本轮或该设置失败并记录错误，进程与远端会话保持连接；只有进程退出、输出损坏等传输异常才关闭连接。

## 存储、架构与开发

### 存储结构

外部绑定、配置与原始执行历史保存在 DSH Host 的 `acp_workbench` storage domain（`version: 1`，`per-record` 布局），DSH 原生消息仍由核心保存：

| 表名 | 用途 |
| --- | --- |
| `providers` | 提供方配置、已勾选模型与缓存的 CLI 能力/模型发现信息 |
| `sessions` | 外部会话绑定元数据、`native` 关联与各轮运行摘要 |
| `chunks` | 原始 ACP 事件分块（每块 64 条，150 ms 合并刷盘，写后仅保留活跃尾块） |
| `checkout_links` | 共享工作树参与会话的关联记录 |
| `scripts` | 各工作目录 `paseo.json` 脚本最近一次运行状态与输出尾部（上限 8 KiB） |

原始历史可能包含代码片段、工具参数与 CLI 日志，目前不自动裁剪。

### 模块划分

| 模块 | 职责 |
| --- | --- |
| `lib/index.js` | Cordis 插件入口、owner 鉴权 HTTP/SSE 接口（`/acp-workbench/*`）与 `acp_workbench` 工具注册 |
| `lib/transport.js` | 基于受管子进程的 NDJSON JSON-RPC 传输、请求超时与优雅退出 |
| `lib/store.js` | `acp_workbench` 存储域管理、串行化队列与分块历史分页 |
| `lib/manager.js` | 外部会话生命周期、探测/模型发现/历史列表与交互仲裁 |
| `lib/native.js` | `acp-*` LLM 适配器、`SubagentProvider` 注册、上下文交接与流式事件转换 |
| `lib/trace.js` / `models.js` / `forms.js` / `notices.js` / `usage.js` / `activity.js` | 轨迹增量折叠、模型变体与思考强度映射、表单校验、提醒与用量投影、活动分组 |
| `lib/projects.js` / `checkouts.js` / `shared.js` / `project-files.js` / `scripts.js` / `service-ports.js` / `review.js` | 项目启动与配置复用、工作树检查/重建/共享、文件检索与浏览、脚本与回环端口探测、项目审阅 |
| `lib/client.js` | 浏览器端界面组件（复用 DSH primitives 与 design tokens，共享一条 SSE 连接） |
